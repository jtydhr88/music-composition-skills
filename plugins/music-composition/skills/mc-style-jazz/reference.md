## 1. 和弦 → 音阶对照

### 1.1 大调音阶的调式

| 调式 | 和弦 | 避免音 |
|---|---|---|
| Ionian | △7 | **4**（与三音半音冲突） |
| Dorian | m7 | 6（视上下文） |
| Phrygian | m7 / Sus♭9 | ♭2（它同时是特征音） |
| **Lydian** | **△7(♯11)** | ★ **无**——这是它比 Ionian 更"开"的原因 |
| **Mixolydian** | **属7** | 4 |
| Aeolian | m7 | ♭6 |
| **Locrian** | **m7(♭5)** | ♭2 |

★ **"避免音"不是不能用，是不能停在上面。**

### 1.2 旋律小调的七个调式（★ 爵士的核心资源）

| 级 | 名称 | 和弦 |
|---|---|---|
| 1 | Melodic Minor | **mMaj7**（小大七） |
| 2 | Dorian ♭2 | **Sus♭9** |
| 3 | Lydian Augmented | **△7♯5** |
| 4 | **Lydian Dominant** | **7(♯11)** ★ 最易搬进流行 |
| 5 | Mixolydian ♭6 | 7(♭13) |
| 6 | Locrian ♮2 | **m7(♭5)** |
| 7 | **Altered（Super Locrian）** | ★ **7alt** —— 爵士声音的核心 |

★★ **可互换性**：同一个旋律小调生成的这些和弦可以互相替代。
**想的不是单个和弦，是"现在在哪个旋律小调上"。**

### 1.3 减音阶与全音音阶

| 音阶 | 配什么 | 要点 |
|---|---|---|
| **半全减音阶** | V7(♭9) | ★ 减七和弦是 V7♭9 的"伪装"；bebop 之后直接用 V7♭9 |
| **全半减音阶** | dim7 | ★ **以小三度重复** → 一个 voicing 通用于多个 V7♭9 |
| **全音音阶** | 7(♯5)、增和弦 | |

## 2. Levine 的细则：SKILL §3 没展开的那几条（p0055–0110）

### 2.1 避免音的正确用法（p0055–0059）

Levine 自己说 "avoid note" 是个坏词，更准的是 **"handle with care"**（p0055）：I△7 上的 4 度当经过音快速带过几乎听不出不协和；**刻意用它时通常解决到下方的三音**（Stella By Starlight 第 9 小节 E♭ 到 D，p0056）；在 outside 段落或长时间停在一个 △7 上时，4 度反而可能是最有意思的音（p0056）。属七上的 4 度（11）同理，可以弹了再下行半音到三音（p0059）。
**不要把协和当好、不协和当坏。不协和给张力、解决与能量**（p0056、p0059）。

### 2.2 Lydian 什么时候用、什么时候别用（p0057–0058）

- 不必等和弦记号出现 ♯4 才升，几乎任何 △7 都可以；**作 IV 级的 △7 尤其好听**，fake book 常不标，因为它是可选的（p0058）。
- Lydian 在流行曲上可能 "out of character"，Oliver Nelson 编 Yesterday 用过（p0057）；它不是现代发明，1926 年 Someone To Watch Over Me 的 bridge 首和弦、1893 年 Happy Birthday 第 6 小节都是（p0058）。
- 记号：是 4 度升高，不是 5 度降低；1960 年代前叫 ♭5，之后按调式思考改叫 ♯4／♯11（p0057、p0060）。

### 2.3 Sus 和弦怎么排（p0061、p0064–0065）

定义：**"一个 4 度听起来不像避免音的 V 级和弦"**（p0061）。
- 排法：右手放**比根音低一个全音的大三和弦**（Dsus 右手 C 大三），其中一个音八度重复加厚（p0064）。
- 1960 年代之后 **3 度与 4 度可以同时出现，但 3 度必须在 4 度之上**；反过来会出现小九度，"最后一个不协和音程"（p0064–0065）。
- Miles Davis 在 In Your Own Sweet Way 里 A♭sus 与 A♭7♯11 交替（p0064）。

### 2.4 旋律小调：互换性的边界与特征音（p0091–0095）

- 互换性成立的原因是旋律小调**没有避免音**，同一调内所有和弦的音高集合完全相同，所以在 F-△ 上的任何乐句和 voicing 可以直接搬到 Gsus9、A♭△♯5、B♭7♯11、Dø、E7alt 上（p0091）。
- ★ **这条不适用于大调**：D-7 与 C△ 同出 C 大调，但 D-7 的 voicing 里有 F，是 C△ 的避免音（p0091）。
- "Think key, not chord"：你弹的是整个调，不是和弦（p0092）。
- **特征音**：旋律小调的 3、5、7、9 组合与 1、3、5、7 组合只属于这一个旋律小调，别的旋律小调和任何大调都没有；弹它们立刻确立调性（p0095）。
- 记忆法：钢琴上调号就是"除了某几个音全弹白键"，G 旋律小调是除了 B♭ 与 F♯，D 旋律小调是除了 C♯（p0092–0093）。

### 2.5 减音阶与全音音阶：对称带来的"重复律"（p0096–0110）

| | 减音阶 | 全音音阶 |
|---|---|---|
| 构造 | 半全交替，八音，**对称**，所以只有三个（p0096–0097） | 全由全音，对称，所以只有两个（p0108） |
| 重复律 | ★ **一切都可以以小三度重复**：lick、和弦、voicing 都行；同一个 voicing 通用于四个 V7♭9（p0100–0102） | ★ **一切都可以以全音重复**，也就可以按大三度、三全音重复；无避免音，同一音阶内一切可互换（p0108–0109） |
| 记号 | | 配 G7♯5，写 G7+ 易混（+ 指 5 度），写 G7♭13 有点危险（暗示 ♭9 ♯9 即 alt）；**安全起见写 G7♯5**（p0108） |
| 限制 | | 缺少西方音乐一半的音程（小二、小三、纯四……），**同质感强，最好小剂量用**；100 首 fake book 曲子里只有一两首带全音和弦（p0109）；很多乐手直接用 **alt 替代全音和弦**（Stella 第 17 小节 G7♯5 弹 G7alt，p0110） |

情感色彩速记（p0109）：△7 快乐平静，大三和弦胜利，旋律小调黑暗悲伤神秘，属七张力，减和弦极端张力，全音音阶另成一格。

### 3.1 五度圈展开的三个成品配方（Valerio p0028–0033）

静态的进行要"展开"，办法是沿五度圈逆时针填进去。三个可以直接抄的配方：

| 要连接 | 填法 | 成品（C 大调） |
|---|---|---|
| **I → V** | 沿 A–D–G 的五度关系 | Cmaj7 – Am7 – Dm7 – G7 |
| **I → II** | 从 B7 起走四个五度 | Cmaj7 – B7 – Em7 – A7 – Dm7 – G7 |
| **I → IV** | 跨四个小节走七个五度 | C6 – Bm7♭5 – E7 – Am7 – D7 – Gm7 – C7 – F7 |

**五度与半音的功能等价**：五度圈上一步下行五度，可以换成三全音替代后的半音下行（Dm7 – G7 – Cmaj7 ↔ Dm7 – D♭7 – Cmaj7）。
所以上面任一配方里的属七都能换成它的三全音替代，把一条五度链改写成半音下行的低音线（p0033）。
邻音和弦、倚音和弦在 `mc-harmony` reference §2.8。

## 5. 属功能的家谱：副属、扩展属、替代属、相关 II-7（陈云强《爵士和声》）

### 5.1 副属还是扩展属，看它落在和声节奏的哪个位置

非主属功能的属七和弦，**在弱位上是副属和弦**（向下纯五度解决到自然和弦）；**在强位上是扩展属和弦**（以纯五度下行连成一串属七，直到出现非属功能的自然和弦）（p0134 前后）。

| | 主属七 | 副属 | 扩展属 |
|---|---|---|---|
| 位置 | 多在弱位 | 弱位 | **强位** |
| 根音 | 5 音 | 自然音 | 多用 **6、3、7、2 音**；根音是 1 或 4 音时视为借自布鲁斯 |
| 解决 | 到任一自然和弦 | 通常下五度，可**假解决** | 链式下五度 |
| 张力 | 全部六种变化张力 | 多用自然音 | |

（p0134、p0138、p0140）**假解决**：弱位上的副属不解决到自然和弦，改解决到扩展属或其他非自然和弦，标记仍按副属但加括号。
它和勋伯格的伪终止（`mc-harmony` reference §7.4）、Kachulis 的虚伪终止（SKILL §3.1）是三家对"该到没到"的说法，并排看。

### 5.2 相关 II-7：任何属七前面都能塞一个

**任何具有属功能的属七前面，都可以加入与它根音纯五度下行的小七和弦**，自然与否皆可；是自然和弦时叫双重功能的相关 II-7（p0145–0147）。
副属链与扩展属链的每一环前面都能插它的相关 II-7，插完仍是链。这就是"连锁二五"的生成规则，`mc-harmony` reference §3 只说了"可连锁"。

### 5.3 副属的音阶由目标和弦决定

| 副属 | 音阶 |
|---|---|
| V7/II、V7/III、V7/VI | Mixolydian ♭9 ♭13（V7/II 是 ♭13） |
| V7/IV、V7/V | Mixolydian |

★ **机理**：4 音在所有副属的音阶里都是避用音，因为它就是目标和弦的根音（p0126–0132）。变化音阶清单（♭9、♭13、♭9♯9、♭9♯9♭13、Altered）逐个标避用音，Altered 没有避用音。
替代属与替代相关 II-7 的张力一律可用 **9、♯11、13**，不必看是否自然音（p0225）。

### 5.4 主属七不一定回 I

V7 可以改去：自然替代 **III-7、VI-7**；非自然替代 **♯IV°7、♭IIImaj7、♭VImaj7、♭IImaj7**（后四个借自小调调式转换，**和弦音阶一律 Lydian，无避用音**）。
非自然替代只是暂时过渡，最终仍回 I，**第一个替代和弦与最后的 I 都必须在强位**。现成的链：♯IV°7 → IV-7 → III-7（可用 I/3 代）→ ♭III6 → ♭IImaj7 → I。

替代扩展属两种链式：**交替链式**（原链每隔一个换成替代属，根音变成小二度下行；看第一个属和弦根音是否自然音来判别）与**楔入式**（相邻两个扩展属之间塞一个替代属，两者同时解决到下一个）。

### 5.5 转调的三分类（p0250 前后）

直接转调（无关联、近关系、平行调式）；轴心转调（以自然和弦或调式转换和弦为轴心）；属和弦转调（把原调最后一个属七当新调的主属七、副属七、替代属七或非属功能属七）。
与 `mc-modulation` §3.5 黄虎威的九条做法对照用。
