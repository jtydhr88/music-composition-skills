# 配器（Orchestration）

**这个 skill 管的是"这条线该由谁来奏"，以及"几件乐器凑在一起会变成什么音色"。**

配器不是给写好的音乐"配上乐器"——**乐器的选择本身就改变音乐**。
同一个和弦，弦乐持续奏和木管断奏是两件不同的事。

> **和相邻 skill 的分工**：本 skill 决定**用谁**；
> `mc-texture-layering` 决定**谁占哪个频段、谁和谁让路**；
> `mc-arrangement-arch` 决定**谁什么时候进、什么时候退**。
> 三者常一起用，但别在这里写频段预算和进退场表。

## 1. 动笔前必填

| 必填 | 问法 |
|---|---|
| **① 这条线的角色** | 旋律／低频／和声铺底／织体／色彩／记忆点？（用 ARR-SPEC 的 role 取值） |
| **② 纯音色还是混合** | 要一件乐器的个性，还是要一种新音色？ |
| **③ 音区** | 具体到音名区间。"中音区"不算填了 |
| **④ 演奏法** | 持续／断奏／拨奏／加弱音器……**这一项决定融合度，见 §3.5** |

**自检**：四项答完，你应该已经能说出一个具体编制，而不是"弦乐加木管"。

---

### 1.1 ★ 总开关：先判织体类型，再决定要融合还是要分离

后面 §2 到 §6 全部手段的方向，取决于这一步（杨立青 p0240–0241）：

| 织体类型 | 是什么 | 配器原则 |
|---|---|---|
| **同质性** | 只含一种因素，各声部性质与呈现形式（尤其节奏形态）同一：齐奏型、和弦音束型、分部写作型 | **合唱式配器**：求最大限度的平衡、融合、统一 |
| **异质性** | 含两种以上性质不同的因素：复调、旋律加伴奏、点描 | **色调分离**：各因素之间靠音色、音区、力度分开；每个因素内部仍保持音色的纵向亲和 |

同质性要问三件事（p0241）：选的音色合不合这段的表现意图；写法能不能发挥这件乐器的音区、力度、技术；几种音色合起来能不能真的融成一体。
异质性的目标是把各成分在音色、音区上剥离，分清主次，排成近景、中景、远景的立体结构（p0241），
终点是马勒说的"最大程度的清晰性"，勋伯格说的"凡写在纸上的都应能被听见"（p0241）。

★ **旋律加伴奏型织体的最根本原则就是调动一切手段让层与层的色调分离**。
流行编曲几乎全是异质性织体，所以本 skill §3 讲的"混合"只在**一个因素内部**用，**因素之间不混**。
分离的六个手段在 `mc-texture-layering` §3.4。

## 2. 纯音色还是混合音色

这是配器的第一个岔路口，**两条路要的东西相反**：

| | 纯音色 | 混合音色 |
|---|---|---|
| 要的是 | 那件乐器的**个性** | 一种**新的、听不出成分**的音色 |
| 代价 | 音量与厚度有限 | 个性被磨掉 |
| 适合 | 需要被认出来的线（主奏、solo、记忆点） | 铺底、需要厚度、需要陌生感 |

**判据**：如果听众应该能说出"这是双簧管"，用纯音色；
如果听众应该只感觉到"一种温暖的厚度"，用混合。

**失效条件**：流行/电子编曲里这条界线更模糊——合成器音色本身常是"混合"的结果。
但决策仍然成立：**你要的是可辨识还是不可辨识**。

## 3. 混合的三种形态

### 3.1 同度混合（unison）

不同乐器奏同一个音高，**融合度最高**，成分最难分辨；但融合与否取决于挑谁来叠。同组内、音色相近的两件同度叠最自然（例 VII-11，英国管＋大管，杨立青中册 p0032）。跨组叠先找**"接触点"**：大管＋大提琴、单簧管/英国管＋中提琴、长笛/双簧管＋小提琴一类传统配方（p0033），挑不到接触点容易生硬；叠多了会"中和"（§3.4），演奏法不合也会拉开（§3.5）。

### 3.2 八度叠合（coupled / 挂合）

★ **谁在上不按总谱顺序，按谁在这个音区更强**（逆序组合，杨立青中册 p0046）。
单簧管中音区偏弱，但 c² 以上的"小号音区"饱满明亮、力度好；双簧管中低音区却比同音区的单簧管饱满得多。
所以把单簧管放高八度、双簧管在下面托，比按自然顺序排更鲜明有力。
里姆斯基批评这种排法"音区混杂"，作者不同意；德彪西还有纯为色彩的逆序组合。
**做法**：叠八度时，先看两件乐器各自在这两个音区谁强，强的那个放它强的位置。

不同乐器相隔八度。理论家称为**"音色的挂合（coupled）"或"叠合"**，
**融合程度不及同度混合** (p0039)。

> **位于高八度的乐器，常起着加强下方乐器泛音的作用** (p0039)。

这是八度叠合最重要的一条：高八度那件不是"又一条旋律"，
它在**给下面那件乐器点亮泛音**。所以它该用什么音色，取决于你想让下面那件亮成什么样。

**例 VII-17 罗西尼《塞米拉密德》**：一系列不同类型的木管组八度叠合与纯音色交替，
色彩变化异常丰富，**且几乎每一种"挂合"的音色成分都可清晰分辨** (p0039)。
→ 八度叠合的"不完全融合"不是缺点，是可用的效果。

### 3.3 不同音组的叠合 —— "染色"

弦乐与木管**分别置于不同音组**，不形成任何同度结合时 (p0039–0040)：

- 弦乐通常是占优势的"主导"音色
- **但另一音组上的木管一般不会被完全淹没，而是起"染色"或增加亮度的作用**
- **这类写法在古典时期相当典型**（例 VII-18 海顿《第九十四交响曲》IV，G 大调）

**用法**：想要"听不出加了什么，但整体变亮了"——用这条。

### 3.4 ★ "中和"现象：加得越多，个性越平庸

这是最反直觉、也最容易踩的一条 (p0037)：

> 在音区相对等的条件下，**数量上占优势的乐器通常对总音响有决定性影响**。
> 但在弦乐与木管结合中，有时**不同类木管互相"中和"后，"磨钝"了各自的音色个性，显得"平庸"，
> 反而使弦乐（如第二小提琴）的色彩显得十分鲜明、突出**。

**例 VII-15 马勒《第一交响曲》IV（降 B 大调）**：
10 支木管与第二小提琴同度结合，**木管音色互相抵消，反衬出第二小提琴的鲜明色彩** (p0037)。

**这条的实际含义**：
- 你以为加了 10 支木管会得到"很厚的木管音色"，实际得到的是"被磨平的背景"＋"突出的弦乐"
- 所以**如果你想突出某件乐器，一个办法是在它周围堆一堆会互相中和的乐器**
- 反过来：**如果你发现某个声部意外地突出，检查是不是它周围的东西互相中和了**

**自检动作**：混完之后问自己——我听到的是"一种新音色"，还是"一堆被磨平的东西加一个冒头的"？

### 3.5 演奏法决定融合度

> **在不同组混合音色的结合中，不应忘记各乐器的演奏法对其音响融合度的影响** (p0038)。

**例 VII-16 勋伯格《乐队变奏曲》**（Presto ♩=120）(p0038)：
- 第 441 小节：长笛被竖琴与钢片琴重复。**因长笛用了断音奏法，其音响的时间过渡特性与装饰乐器相近，结合尚称融洽**
- 第 448 小节：单簧管与竖琴**因演奏法（＝时间过渡特性）的差异，形成了音响上一定程度的分离**

**核心**：融合与否，看的是**时间过渡特性**（起音与衰减的形状）是否相近，而不只是音色明暗。
拨奏的竖琴和断奏的长笛能融；和持续的单簧管就融不了。

**这条在 MIDI/合成器上同样成立**，而且更明显——见 §7。

### 3.6 一条线在时间上怎么换颜色（杨立青中册 p0059–0063、下册 p0327–0342）

§3.1 到 §3.5 讲的是纵向的混合，这一节讲**横向**：同一条线沿时间怎么变色，接口怎么处理。

**四法**（中册 p0059–0063）：

| 法 | 做什么 | 要点 |
|---|---|---|
| **音色对置** | 不同音色直接对置、交替 | **交替要与乐句或动机结构的划分吻合**（p0059）。贝多芬《英雄》里三音动机双簧管 → 单簧管 → 长笛 → 小提琴环环相扣，形成音色变化的韵律，最后过渡到全奏（p0060–0061）。点描写法的基本原则也是它 |
| **逐层叠加与削减** | 每层加一件或减一件 | 不只改音色复杂度，也造成力度渐强渐弱、线条幅度扩缩（p0061）。削减是"剥开层层茧壳直到单簧管露出本色"（p0062） |
| **音色偷换** | 在一条线的基本色调上，不断换用相近但有细微差别的乐器去染 | 色彩的含量与质地频频微变，浪漫派之后常见（p0062） |
| **音色转调** | 通过一个**中介色调**把线条从 A 换到 B | 最简单的做法是让 A 与 B 短暂交叠，以此为媒介（p0063） |

**流行里的对应**：换 pad 先叠一层中介音色再撤掉旧的，就是音色转调；副歌每遍多一件就是逐层叠加；同一条 riff 每四小节换一件乐器就是对置。

**转接的两种接口**（下册 p0336）：各环节尾首相互叠置的**交叠式**，与无重叠的**断口式**。前者求过渡渐进平顺，后者求轻快流畅或避免尾首交叠造成的重音；
同一乐句里可以并用，被切成细小单位的快速经过句一律交叠式钩连（p0339）。

**掩盖断痕的手法**（p0339–0342）：重叠两个音而不是一个；让接口与节拍重音错位；用一条不转接的声部盖住接缝。三条都是为了增强各结构单元的"一体化"程度。

**呼应与回声**（p0327–0331）：呼应发生在相同或相似材料的动机之间，**音色、音区、幅度至少有一样对比，力度与奏法大体相当**。
回声是呼应的一种：**先强后弱、强弱差很大到有空间感**，且主客体多用**同类**音色。
★ 最省力的回声是**人工残响**：用一件弱力度音色的长音去重叠强句的尾音，往往带 sfp 式的突弱（p0330）；
让回声那一件在前一拍以 p 提前叠入再延留，突变会显得自然（p0331）。

### 3.7 叠合的三类与变化叠合的五型（杨立青中册 p0150–0155）

§3.1 到 §3.3 讲的都是**原样叠**。真正常用的是叠一层不一样的：

| 类 | 做什么 |
|---|---|
| 完全叠合 | 不同音色完全重叠，产生混合色调 |
| **局部叠合** | 只把声部里最有特征的部分（甚至个别环节）用别的乐器局部重复加以强调 |
| **变化叠合** | 重叠的声部在构成上有程度不等的差异 |

变化叠合五型（p0150–0151）：**动态特性变体**（同音高节奏，换成完全不同时间过渡特性的奏法，连音叠断奏）、**简化变体**、装饰变体、节奏性变体、和声性变体。

**简化变体的做法**（p0151）：从基本声部里抽出若干骨架音，构成一个始终与主线平行、又有一定独立意义的"框架声部"，
让起伏大或形态复杂的织体有清晰轮廓。两条规则：
- **变体与骨架要用对比音色**；同类音色则奏法音区必须分开（p0151、p0154）
- ★ **简化变体的力度标低一级**，否则整体发闷（p0155）

流行编曲里"pad 跟着分解和弦走"就是简化变体，pad 比琶音层低一档力度这条几乎没人写进规格单。

### 3.8 两个乐器组的和声层怎么合（杨立青中册 p0074–0079）

| 式 | 做法 | 结果 |
|---|---|---|
| **并置组合** | 两组的和声层完全重叠，各自都有完整和声 | 最丰满缜密，共鸣好（p0074） |
| **局部重叠** | A 组完整，B 组只叠其中的骨架声部 | **A 组色调占优**（p0075）；反过来弦乐完整、木管圆号局部叠也常见 |
| **分层组合** | 各组都不完整，各自的"和声面"拼成总和声，面可以不接壤也可以部分重合 | 均匀度最差、稍有闪失就失调，**但处理得当色彩最奇**（p0078） |

流行里"弦乐组＋pad＋铜管"三层怎么叠就是这三式。写规格单时说清是哪一式，尤其分层组合，要逐音检查有没有空洞。

### 3.9 强调五法：想让一处被听见，叠什么（杨立青下册 p0275–0288）

| 法 | 做什么 |
|---|---|
| **节奏性强调** | 在承担基本节奏的层里，用另一种音色**周期性地重叠它的节拍重音**（p0275）；★ 让强调点的周期与节拍重音周期**错位**，逻辑重音与节拍重音不一致就产生"失重"，节奏趣味大增（p0277） |
| **色彩性强调** | 在以某种音色为基调的段落里，用一种相异音色**只叠最具特征的部位**（p0279）。杜卡《小巫师》：弱音器弦乐定基调，骨架音上短笛长笛轻快弹吐，动机用竖琴与独奏弦乐泛音勾勒 |
| **力度性强调** | 心理力度的高点（旋律顶音、骨架音）不一定是物理响度高点，用另一件音色叠上去强调它（p0283–0284，详见 `mc-sound-design` §3.6） |
| **结构性强调** | 用相异音色重叠、勾勒某乐句或动机**在结构形态上最有个性的那部分**，让轮廓更鲜明（p0286） |
| **音响动态的强调** | 叠一层起音快的音色去改造慢起音层的音头（p0287，`mc-sound-design` §3.6） |

**用法**：规格单里"主角序列"说这一段谁是主角之后，再答一句**用五法里的哪一种把它叠出来**。五种都不用，主角就只能靠推力度，那正是 §4 说的最弱的一档。

★ 节奏性强调的极端形态（p0276）：弦乐层里不规则的重音用一组圆号 sf 加强，段落获得 2/4、2/8、6/8、3/8 交替的效果，强调本身升格成了「节奏性主题」。

## 4. 平衡：数量与音区

**基本规律** (p0037)：**音区相对等时，数量占优势的乐器对总音响有决定性影响。**

但"数量"要按实际编制算，不是按声部数：

| | 常规交响乐队 |
|---|---|
| 第一小提琴 | 约 16 人 |
| 第二小提琴 | 约 14 人 |

> 所以**对单个演奏员困难的双音片段，在乐队里用分奏（divisi）来演奏就变得相当简单** (p0067)。
> —— 这是弦乐组独有的便利：写不了的双音，拆成两个声部就行。

**自检动作**：你写的平衡是按"几条线"算的，还是按"几个人在奏"算的？

### 4.1 ★ 先于数量的一条：音区要对等

数量只是第二条。第一条是**各件乐器要落在力度对等的音区**，都在强音区或都在弱音区，才容易平衡（杨立青中册 p0021）：

| 组合 | 结果 |
|---|---|
| 长笛＋大管 | 音区不对等，**无论强奏弱奏大管都冒尖** |
| 双簧管＋单簧管 | 强奏尚可，弱奏时双簧管过强 |
| 双簧管＋大管 | 音区基本相等，强弱都均匀融洽 |

再加一条：和声性结合里**泛音丰富、音色个性强的乐器即使音量相同也会冒尖**（p0021）。
"平衡只是相对概念"，大多数织体不需要绝对平衡（p0021）。

### 4.2 横向的平衡：转接时后一件要接得住前一件

平衡不只是纵向的，还有**线条在乐器之间传递时响度能不能延续**（p0021–0023）。
书里的估算：第一小提琴声部约 83.5 dB，长笛独奏约 72 dB，a2 也只到 75 dB（p0022）。
所以低音区的长笛接不住大管的势头（80 dB 以上），该换双簧管或单簧管去接；
双簧管往下接的话也要换长笛或单簧管，不然线条在接口处出现响度断层（p0023）。
**做法**：写转接前先比两件乐器在接口音区的响度，接棒者不能比交棒者弱一档。

## 5. 让某一组透出来的三个条件

木管写了听不见，是最常见的配器失败。西贝柳斯《第二交响曲》I 给出了正面样本 (p0040)——
**木管色调清晰地从总音响中透现出来**，原因有三，缺一不可：

1. **木管乐器的数量有所增加**
2. **采用了八度叠合与同度混合相结合的处理方式**（不是单一手法）
3. **最高层的长笛位于它强有力的音区，发音异常鲜明，富于光彩**

**第 3 条最容易被忽略**：同一件乐器换个音区，穿透力可以差一个量级。见 §6。

## 6. 音区即性格

**同一件乐器在不同音区是不同的乐器。** 以小提琴的四根弦为例 (p0065–0067)：

| 弦 | 性格 |
|---|---|
| **G** | 四弦中最粗、声音最圆润低沉。**移到该弦高把位时声音变得非常紧张**——因为振动部分持续缩短 |
| **D** | Adler：音质可能是四弦中**最无特色**的，但蕴含温暖与抒情，向高把位移动时更趋醇厚。★ 杨立青（p0129）说法相反：四弦中**发音最甘甜动人**，弱奏时柔和明亮，有「高贵、诗意的魅力」（卡塞拉语）；指定 D 弦通常是要比 A 弦更结实丰富的音色。两家并排，按本库体例不裁决 |
| **A** | **第一把位声音特性最显著**；高把位会丧失部分辉煌与力量，更适合柔和抒情。想在高音区要辉煌，应换到 E 弦 |
| **E** | **音质最辉煌**的一根，音域顶点极其明亮；但**用柔和力度演奏时也能发掘出宁静、神秘的特质** |

**指定用哪根弦的记法**：`sul E` / `sul A` / `sul D` / `sul G` (p0065)。

**什么时候该指定、什么时候不该** (p0065)：

> 当某个音在几个位置都能奏出时，**明确规定演奏者在哪个位置奏出该音将是毫无意义的**。
> 如果作曲者相当熟悉乐器指法，可以在总谱和分谱上标出确切指法以获得想要的音色。
> 除此之外，**指法最好由演奏者自己决定**。

**空弦音的特殊性** (p0065)：
- 空弦无需受手指控制影响，**振动潜力更大**
- 快速片段里空弦与按弦混用不会不谐和
- **但慢速而富有表情的片段里，通常希望所有音音色一致，否则空弦音会格外突出**
- 例：勃拉姆斯《第一交响曲》IV 第 61–75 小节全在 G 弦上，"要注意听在 G 弦空弦上创造的振动音响"

**推广**：这套逻辑不止于弦乐。任何乐器都有"强音区/弱音区/换声点"，
**写之前先问这件乐器在这个音高上是什么状态**。具体音域表见 reference.md。

## 7. MIDI 配器：什么变了，什么没变

**没变的**：上面 §2–§6 全部成立。中和现象、演奏法决定融合、音区即性格，
在采样音源上一样发生——因为采样本来就是录的真乐器。

**变了的四件事**：

| | |
|---|---|
| **① 没有演奏员的自动修正** | 真人会自己调整音准与平衡，采样不会。所以配器上的失衡在 MIDI 里会**原样暴露** |
| **② 演奏法要显式切换** | 断奏/连奏/拨奏在真乐队是一句话，在 MIDI 里是换 articulation 或换音色层。**§3.5 说的融合度差异，你得手动制造** |
| **③ 分奏的便利消失了** | 真乐队 divisi 很容易，MIDI 里 16 把小提琴是一个采样。想要 divisi 的厚度，得用多个实例＋微差 |
| **④ 空弦、把位、换弦都不存在** | §6 那套弦性格，采样音源通常不区分。**想要 sul G 的紧张感，只能靠选音色层或用独奏采样** |

**实践判据**：MIDI 做出来"假"，多半不是音色不够好，而是
**把真乐队里由演奏员承担的那部分决策省略了**——力度起伏、演奏法变化、音区选择。

> 详细的 MIDI 配器手法见 [reference.md](reference.md) §5：§5.1 配器会用到的 CC，§5.3 让采样活起来的清单（分层与 CC#1 交叉淡化、琴键切换两种录法、叠音色干湿比、每组叠一件真乐器、CC#7/CC#11 包络、力度到起音与滤波器、量化起点、自然噪声）。

## 8. 民族管弦乐：与西方管弦的差异与配器原则

**§2–§6 的机理在民乐队里照样成立，但乐器换了，先把四件事翻过来想。**
本节引用：未标书名的页号都是杨春林《中国民族管弦乐配器法教程》；朱晓谷、李民雄单独标出。

| 差异 | 后果 |
|---|---|
| 四个组：吹管／弹拨／拉弦／打击，弹拨组是西方乐队没有的 (p0012–0013) | 多了一整组"点状"发音体，点与线的融合是民乐配器的主矛盾 |
| 胡琴类**音区越高，音量与力度反而衰减**（皮膜达不到高频振动）(p0038) | 西方"越高越亮"的直觉失效；高潮别靠把二胡写高 |
| 梆笛、曲笛、高音唢呐**低八度记谱**，倍低胡高八度记谱 (p0352) | 谱面"不高"的笛子和声实际很高 (p0162)；配器按**实际音高**想 |
| 常用总音区七个音组六个八度：最低 E（倍低胡）到 g³（G 调梆笛）(p0351) | 比交响乐队窄；提琴组低音区民族拉弦"束手无策"，只能靠弹拨帮 (p0442) |

**术语**：同一旋律同度陈述叫**单音组**，隔一个八度叫**双音组**，两个八度叫**三音组**……无论几个音组，性质都是**单声部**，绝不可理解为平行八度 (p0045)。

### 8.1 四组的性格与音区

| 组 | 性格 | 音区要点 | 自检 |
|---|---|---|---|
| **拉弦** | 乐团基础声部，线条式、最富歌唱性 (p0026, p0072)。高胡／二胡／中胡是皮振动，大提琴／低音提琴是板振动，同度结合音色不统一 (p0037) | 二胡最好的音区在不加线的高音谱表内 (p0040)；高胡担高音，低音区略带鼻音 (p0034)；中胡担和声，音区不宜高否则失去浑厚 (p0041)；中胡最低只到 G，全组**缺次中声部** (p0057, p0061) | 四部分配：高胡＝高音、二胡＝中音、中胡＝次中音、低胡倍低胡＝低音，中胡层是共鸣的"腰" (p0056–0057)。高胡二胡中胡**只能单音**（最多五度平行）(p0051)，多音必须 div.；分部后整组音量减弱，适合弱奏与和声色彩，强奏别分 (p0054) |
| **弹拨** | 点状发音 (p0275)；音域普遍比拉弦宽——"拉弦占音色优势，弹拨占音域优势" (p0224)。音色分两组：柳琴＋扬琴＋中阮紧而直，琵琶＋古筝松而脆 (p0094) | 柳琴担高音、琵琶中音、扬琴高中音、中阮中音、大阮低音 (p0074–0088)；全组和声：大阮低、中阮扬琴中、琵琶古筝柳琴高 (p0119)；扬琴各音区都好，最适合和声 (p0120) | 同一旋律里**弹与轮必须统一**，有弹有轮就乱 (p0092)；同音反复用"一弹一轮" (p0093)。古筝五声定弦，纵向和弦尽量不用偏音，横向可用但别快 (p0118)。琵琶与扬琴同音组重复三音效果不佳 (p0120) |
| **吹管** | 乐队的音色调色板与势能来源，高潮几乎总有它 (p0133)。笙能多音、吹吸皆发音，是乐队"融合剂" (p0132–0133)；唢呐音色很难与其他乐器融合 (p0281)，一支唢呐的分贝相当于十六把二胡 (p0415) | 梆笛中音区最好，低音区虚、最高两音尖 (p0136)；曲笛任何音区都好 (p0150)；新笛比同调梆笛低八度、无膜、音色内在 (p0138, p0150)；高音笙 d¹—d³ 最美 (p0150)；低音笙旋律不超 g¹ (p0151)；高音唢呐中低音区好听，**把音区降低效果反而好** (p0152)；中音唢呐音色不美，多做重复与和声 (p0143) | 笛子组没有低音，其和声只能是色彩性和声，别写厚 (p0162, p0267)；唢呐和声要"极端小心"，哨片不稳，且它的中低音区在乐队里已属高音区 (p0162)；高音唢呐和声音区记谱不超过 #c²/d² (p0165)。竹笛一笛一调，总谱必须写明用哪调笛、何时换笛 (朱晓谷 p0014) |
| **打击** | 无固定建制，按曲需要配 (p0192)；力度幅度比其他组大得多 (p0288)。中国打击乐**强用明用**，西方打击乐**弱用暗用**；中西数量约 2:1；人数不超乐团十分之一 (p0220) | 定音鼓使用频率最高，管强调与音势 (p0192)；云锣中音区最好听 (p0206)；木鱼几乎所有欢快节奏都能用 (p0211)；小军鼓、玛林巴与民乐风格不合，慎用 (p0178, p0217) | 四条：非用不可才用；多件同用防互相抵消；只能烘云托月；多考虑兼奏 (p0289)。无音高打击乐与拉弦不产生复合音色，只会原样露出来 (p0292) |

### 8.2 分组结合：谁和谁合得来

**同度结合谁占主导**：拉弦＋弹拨、拉弦＋吹管同度时，音色都以**拉弦为主** (p0256, p0281)；例外是唢呐——一支唢呐对一组高胡，唢呐照样明显 (p0281)。

| 结合 | 好 | 差／条件 |
|---|---|---|
| 拉弦＋弹拨 | 二胡＋琵琶、中胡＋中阮、低胡＋大阮：最实用、使用率最高 (p0228, p0231, p0233)；高胡＋柳琴高音区最友好 (p0226)。原则：**选同音区的乐器结合**——中胡配中阮而不配柳琴，厚度相似 (p0235) | 高胡＋琵琶"高不成低不就" (p0227)；高胡＋古筝、中胡＋柳琴不实用 (p0228, p0231) |
| 拉弦＋吹管 | 拉弦软化、美化管乐音色；管乐加大拉弦音量、强化韧性 (p0267)。低胡＋低音笙最实用 (p0260) | 管乐比弹拨响，平衡先算 (p0267)；唢呐另算 (p0256) |
| 弹拨＋吹管 | 柳琴＋梆笛、琵琶＋高音笙、中阮＋中音笙、大阮＋低音笙 (p0273)；有笙组，和声"非常方便" (p0275) | 点对线的差异是重点 (p0275)。笛子的下滑音柳琴做不了：省掉落音，或改轮奏 (p0271) |
| 打击＋各组 | 与弹拨"都是点"，最易融合 (p0292)；与吹管音量能平衡，"天作之合" (p0295) | 与拉弦：平衡是关键 (p0292) |

**跨组八度叠合的坑**：拉弦（线）与弹拨（点）隔八度结合，音色差异非常明显；解法是**每个音组都用复合音色**——第一音组高胡＋柳琴、第二音组二胡＋琵琶 (p0240)；拉弦＋吹管同理：高胡＋曲笛／二胡＋新笛 (p0263)。**失效条件**：你要的正是点线分离的效果。

### 8.3 全编制：旋律、低音、分部、伴奏怎么分

分部三类（和声式、附着式、对比性）、弹拨组分不分部的六条判据、和声陈述五式与单双音色组的八种搭配在 [reference-minyue.md](reference-minyue.md) §8.4.1–8.4.3。

- **旋律**：三种模式——单组陈述、双组联合、三组共同；其余组不陈述旋律但**不得缺席**，只有无音高打击乐可例外 (p0302–0303)。旋律在高音区最不易被淹没，但民乐队拉弦与弹拨的高音部分相对薄弱（高胡筒小人少），常需加乐器补 (p0414–0415)；中音区旋律是内声部，其他声部要让开该音区 (p0415, p0451)。
- **分层和声**：每组按高／中／低的和声结构一致：高＝笛子组、高音唢呐、柳琴、琵琶、扬琴、高胡、二胡；中＝笙、中音唢呐、阮、中胡；低＝低音笙、低音唢呐、大阮、低胡、倍低胡 (p0352)。叠置**上密下疏中不空**；D—d 次中音区与 G—g 中音区决定共鸣 (p0375, p0451)；密集排列用于强奏与同类乐器，开放排列用于弱奏色彩与不同乐器 (p0375)；不重复三音，七和弦低音用过的音上方不再用 (p0375)。**自检**：笙、阮、中胡这层是不是空的？
- **低音**：拉弦低胡倍低胡＋弹拨大阮＋吹管低音笙低音唢呐；笙唢呐只能是线，胡与阮可线可点 (p0336)；大阮最低音比低胡高大二度，低音唢呐高五度 (p0336)。低音笙与其他低音乐器要按泛音列排，否则"浑" (p0140)；低胡拉、倍低胡拨可做"点线低音" (p0062)；低胡奏旋律时倍低胡与它至少隔五度 (p0062)。
- **伴奏**：节奏式和声一般用八分音符（四分音符出不来律动），常由高音笙、中音笙、中阮担任 (p0359)；弹拨用十六分音符和声避免柱式的浑浊呆板 (p0361)；"按乐器组分工配和声"（吹管旋律、弹拨或拉弦和声）是常规 (p0370)。
- **分部与标记**：吹管两支同类用 a²／I／II (p0347)；笙一般不分部，独奏 solo、齐奏 tutti (p0348)；弹拨双音一般不标分奏，扬琴不分 (p0348)；拉弦 div./unis.，solo/soli/tutti 成对出现 (p0348)；低胡双音须标 div. 或 non div. (p0349)。

### 8.4 处理法（每条带自检）

| 法 | 要点 | 自检 |
|---|---|---|
| 平衡 | 旋律必须清晰；和声不过厚（浑）也不过薄（干硬）(p0414–0415)。同一力度记号不同乐器响度不同，力度标记按乐器分别调 (p0413) | 分部后的音量下降算进去没？ |
| 强调 | 旋律以外的全部乐器帮重音 (p0416) | 是不是只靠了力度记号？ |
| 转接 | 旋律在一条线内换乐器，弥补民乐音域不够；接棒者**提前进入**，交棒者多奏一个音 (p0418) | 换手处有没有重叠？ |
| 增长／收缩 | 口诀"先弦乐，再弹拨，再吹管，最后打击" (p0421)；渐弱靠力度＋减少声部 (p0421) | 渐强渐弱是不是全推给了指挥 (p0450)？ |
| 音势 | 装饰音、滚奏、刮奏的短促推进 (p0422) | |
| 对话呼应／音色对置 | 民间"对句"；同一材料轮流换组 (p0424–0427) | |
| 补充 | 临时加声部，或给终止一个"刹车" (p0428–0432) | |
| 保留 | 重要旋律进入前不用那件音色；旋律在中低音区时其他声部让开 (p0451) | |

李民雄补两条：色彩变换的"节奏"要与乐节乐句乐段划分一致，展开与戏剧性段落宜多变 (李民雄 p0097)；一段音乐立一个**主导音色**，其余变化围绕它 (李民雄 p0100)。

### 8.5 独奏乐器在合奏里

- 定义：单独一件乐器，总谱无任何声部与之相同 (p0394)。原则只有一条：**保证独奏清楚，不被淹没** (p0410)。
- 五法 (p0411)：伴奏音量小；伴奏音区避开独奏音区；伴奏音色与独奏不同类（弹拨伴拉弦、吹管伴弹拨）；音区对比（低音独奏配高音伴奏）；伴奏节奏型与独奏不同。
- 各件：唢呐笛子不易被盖，笙要给它减伴奏；柳琴低音区独奏小心；中阮难突出且高音区不美，用中音区；二胡独奏伴奏多用弹拨；中胡独奏伴奏避开其音区 (p0410)。
- 协奏曲四对比：音色（独奏是唢呐就别用唢呐伴）、音区（为独奏留空）、节奏、力度 (p0412–0413)。

### 8.6 改编与移植

- **改编**＝只有旋律，写全总谱；**移植**＝已有总谱换乐队，不改和声与织体，特殊情况可改调 (p0440)。传统器乐名曲改编**不可改调** (p0440)。
- 移植先看音域再看调性 (p0441)：小提琴↔柳琴全重合；琵琶 c³ 以下、扬琴 g³ 以下、古筝 d³ 以下、高胡 g¹ 以上重合 (p0441)；双簧管→高音笙最佳、单簧管→中音笙、大管→低音笙、小号→高音唢呐（注意八度记谱差）、圆号→中音笙、竖琴→古筝（变化音多则扬琴）(p0444–0447)。**长笛谱不可直接给竹笛**——竹笛低八度记谱 (p0444)。
- 布局：最适合的调性在两个降号到三个升号之间 (p0449)；《花好月圆》用 G 调而非 D 调，整个乐队才"亮" (p0449)；以最佳音域为原则，别把胡琴越写越高 (p0450)；慎用齐奏全奏与最强力度 (p0450)；和声节奏宜宽，分解和弦里加和弦外音以冲淡"洋味" (p0451–0452)。

> 逐乐器的定弦、音域、技法、总谱顺序与移调惯例见 reference-minyue.md §7–§8。

## 10. 写完后必过

- [ ] 每条线都说得出**角色**和**为什么是这件乐器**
- [ ] 混合的地方，说得出是**同度／八度叠合／不同音组**哪一种
- [ ] 八度叠合的地方，说得出**高八度那件是在点亮什么**
- [ ] 检查过**中和现象**：混出来的是新音色，还是一堆被磨平的加一个冒头的
- [ ] **演奏法填了**，且相融的几件时间过渡特性相近
- [ ] 每件乐器的音区**具体到音名**，且确认过它在那个音区是什么状态
- [ ] 平衡按**人数**算过，不是按声部数
- [ ] MIDI 的话：力度起伏、演奏法切换、音区选择三项都做了决策，没有留给默认值

**写民族管弦乐再加这几条**：

- [ ] 四个组**都在场**（只有无音高打击乐可缺席），且说得出旋律是单组、双组还是三组陈述
- [ ] 分层和声的**中声部（笙、阮、中胡）不是空的**——叠置做到「上密下疏中不空」
- [ ] 每件乐器按**实际音高**核对过一遍：梆笛、曲笛、高音板胡、京胡、高音唢呐、海笛是低八度记谱；倍低胡、雷琴、定音鼓是高八度记谱；中阮与传统唢呐必须写明用哪一种记谱
- [ ] 竹笛、唢呐**写明了用什么调的乐器**，中途换乐器的地方也写了
- [ ] 没有把胡琴越写越高（音区越高音量与力度反而衰减）；高潮不靠把二胡写高
- [ ] 分部标记成对：`div.` 配 `unis.`，`solo`／`soli` 配 `tutti`；低胡的双音标了 `div.` 或 `non div.`
- [ ] 风格性技法（滑音、花舌、扫轮、打音这类）在谱上标了，且同一声部统一
- [ ] 移植／改编：先查过音域再定调；传统器乐名曲**不改调**
