# 电子舞曲风格层（EDM / Club）

**这个风格与本库其余部分最大的差别：它不是"歌"。**

> **歌曲类音乐的结构是"内容的序列"（主歌讲这个，副歌讲那个）。
> 俱乐部音乐的结构是"层的加减"。**

所以很多通用规则在这里要重新解释——但**不是失效，是换了个形态**。

## 2. ★ 移植表

| 手法 | 可搬进歌曲类音乐吗 | 说明 |
|---|---|---|
| **层叠加减做形式** | ✅ ★ **可搬，而且极有用** | 它就是 `mc-arrangement-arch` §5"编制即形式"的极端形态 |
| **长 build** | ⚠️ **半搬** | 歌曲类音乐的听众耐心短得多。**缩短到 2–4 小节可用**（= J-POP 的进副歌前期待，`mc-style-jpop` §6） |
| **只有鼓的段落** | ⚠️ 半搬 | 在歌里它是一个有效的减法事件；但**不要做 16 小节那么长** |
| **四踩底鼓** | ⚠️ 半搬 | 强风格标记 |
| **侧链泵动** | ⚠️ 半搬 | ★ 非常强的标记。`example-01` 的 `exclude` 里就明确排除了 `modern sidechain pumping` |
| **绝对量化** | ⚠️ ★ **半搬，且有前提**（§6） | |

| **"purpose determines form"这个思路** | ✅ ★ **可搬，该搬** | §3.2 |

★ **判据**：
> **可以搬走它的结构技术（层叠、build、重复），
> 但不要搬走它的时间尺度（16 小节起步的铺垫）。**

## 3. 结构

### 3.1 典型形状

```
four-on-the-floor 底鼓起
 → 加 hi-hat
 → 加钢琴之类的持续伴奏（以 8+ 小节为单位重复）
 → 正式前奏 → A メロ → サビ
 → 回到只有鼓的段落 → 循环……
```

**特征**：
- **旋律可有可无**
- 结构**长而大**
- 有**只剩鼓**或**只剩 pad** 的段落 → ★ **厚度落差极其尖锐**
- **以鼓为中心**来编

### 3.2 ★ 这个结构为什么成立

**两个理由，都与"在哪听"有关：**

1. **慢慢堆更适合跳舞**
2. ★ **只有鼓的段落方便 DJ 接下一首**

> ★★ **在家里听觉得啰嗦无聊的结构，在舞池上极其有效——目的决定形式。**

**这句话是本 skill 最重要的一句**，而且它可以搬出去：
**任何"这样做对不对"的问题，先问"在哪听、听第几遍"**
（→ ARR-SPEC 的 `intent.listener_situation`）。

### 3.3 节构成

俱乐部曲目内部怎么分段，两种做法要并排看：

★ **靠密度撑形式的做法（DeSantis p0299）**：不靠传统分节，靠"围绕少量素材、持续改变织体密度"来撑住形式。三个具体单位可以直接借：
- **Buildup（堆叠段）**：常见 **16 或 32 小节**（或其倍数），靠不断加层把密度推到本段顶点
- **Breakdown（分解段）**：低能量对比段，常见做法是**去掉全部鼓元素**或反过来**只留鼓**，长度通常比 buildup 短，但仍以 **8 或 16 小节**为单位
- **Drop**：全曲密度最高的段落，可以接在 buildup 或 breakdown 后面；**一首曲子里通常只有 1—2 个**，buildup 和 breakdown 则可以有更多

**经典 dub techno**（如 Chain Reaction 厂牌）走另一个极端：开头的贝斯线或鼓型贯穿全曲，没有明显的分节对比，新素材靠往既有素材上叠加，规模不大换（p0299）。

**判据（p0300）**：和流行乐关系紧的支流，建议还是用更传统的 song form；techno、trance、dubstep 这类"纯电子"流派，少量素材配合密度的持续变化就足够撑起结构感，不必勉强套 verse/chorus。

## 4. Build 与 Drop

### 4.1 build 的本质是期待，不是响度

**堆不上去的常见原因：build 只在加东西，没有在"承诺"。**

有效的 build 要给出**可预测的终点**：
- **滤波器扫频**（cutoff 单向上行 → 听众知道它要到顶）
- **节奏加密**（8 分 → 16 分 → 32 分 → 听众能数出还剩几拍）
- **上行音高**（riser）
- ★ **最后一刻的静止**（→ `mc-style-jpop` §6 的"突然全停再砰地进"）

**build 的第五种终点：Shepherd 音**（Howard & Angus p0248–0250）。频谱只在一个八度内循环，每升半音各分量上移一格，
高的分量渐弱消失、低的分量渐强出现，听感是**无限上升的音阶**，声学上却从没超出一个倍频程。它是唯一一种能无限持续的 riser，
适合不知道 drop 在哪一小节、或要把期待拉得很长的段落。做法：一组八度叠置的分音，各自按一条钟形包络控制幅度。

### 4.2 drop 落不下来的三个原因

| 原因 | 解法 |
|---|---|
| **build 已经和 drop 一样满** | ★ 回到 `mc-arrangement-arch` §2：**能量曲线必须有下降**（62/62 强规则）。build 顶点应该**比 drop 低** |
| **低频在 build 里没让出来** | build 里**切掉低频**，drop 时一起回来——这是"落差"的物理来源 |
| **drop 没有新东西** | drop 必须带一个**前面没出现过的元素**（一个音色、一个 riff） |

### 4.3 ★ 一条要小心的默认值

生成后端在 EDM 提示下会**默认给你 build + drop**，而且往往是**教科书式的**。
`example-01` 的 `exclude` 里排除 `EDM drop` 就是为了这个。

**判据同别处**：**你是选择了它，还是默认落进了它？**

## 5. 层叠即形式

### 5.1 没有旋律时，形式从哪来

> **大多数无声乐的当代电子流派倾向于避免传统的 verse 和 chorus 段落，
> 而是通过「层叠的加减」来创造形式对比。**

**在 ARR-SPEC 里怎么表达**：
- `form[].name` 仍然要填，但**用 `Instrumental` / `Intro` / `Outro`**，
  并在 `note` 里写这一段有哪几层
- ★ **形式实际由 `roster[].entry/exit` 承载**，不由 `form[].name` 承载
- `energy_curve` 变成主要的结构描述

★ 这正是 `mc-arrangement-arch` §5"编制即形式"那一节说的事，EDM 是它的纯粹形态。

### 5.1a ★ 声部进场的顺序本身就是结构：Acid 的经典做法（野崎）

经典 Acid 只有四条轨：riff、贝斯、hi-hat、大鼓。**它们不同时进场，进场顺序是固定的**（p0271–0272）：

1. 只有 riff
2. 加 hi-hat
3. 贝斯上场
4. 最后放出 4/4 的大鼓

★ **大鼓最后进**，这和"先铺鼓再往上叠"的直觉相反。三条配套（p0273）：

- **开场把 riff 的 CUTOFF 压得很低，让它几乎像淡入**。目标是做出"听不出起头在哪"的乐句，直到 hi-hat 进来之前，听众以为拍子和实际差了半拍。节拍歧义是刻意的，hi-hat 一进对上那一下就是效果
- hi-hat 进来之前手动慢慢转开 CUTOFF，让单调的重复不腻。用慢 LFO 或滤波器包络也能做，但作者认为**手动才做得出难以预料的变化**
- **新声部进场时先压前一层的 CUTOFF**：贝斯登场前把 riff 的 CUTOFF 暂时转小，两者不会同时推满互相干扰；大鼓进来后 riff 与贝斯"恣意纠缠"，靠 CUTOFF 与 RESONANCE 两个参数同时转（一个压低时另一个抬高）控制

**推广**：任何 loop 型风格，"谁先进、谁最后进"是一个要写进规格单的决定，不是默认从鼓开始。

### 5.2 重复本身就是堆积

> **重复渗进无意识，唤起半不随意的身体反应——
> 即使没有大高潮，重复本身就构成了堆积。**

★ **这与 `mc-melody` §8 的"反予定調和"表面冲突，实际不冲突**：
- **歌曲类音乐**：听众在**跟随内容**，可预测 = 无聊
- **俱乐部音乐**：听众在**跳舞**，可预测 = 能跟上

**这是一个真实的失效条件**：`mc-melody` §8.1 的"同一乐句重复 3 次以上"那条，
**在俱乐部音乐里不成立**。

## 6. ★ 量化：本 skill 最需要说清的一条

**两家说法要并排看：**

| 出处 | 说法 |
|---|---|
| DeSantis (p0154) | 在 **Techno、House、Electro、EDM** 里，**绝对量化是完全合适的**，常伴随完全一致、无变化的力度 |
| 本库佐证表 | 「不该全声部严格对齐网格」**62/62 命中**，强规则 |

**调和——关键在"全声部"：**

- ✅ **鼓组可以绝对量化**，如果风格要求
- ❌ **但不能全曲每一件都在网格上**——那是生成模型的指纹，不是任何风格的要求
- ★ **量化是逐乐器的决策，不是全局开关**

**实务做法**：鼓组 100% 量化，**留一件演奏的东西不量化**
（贝司、采样素材、人声、或一层 pad 的起音）。

### 6.1 如果确实要全部为 0

判断本身在 §6 已经讲完，这里只定写法：**在 `checks.exemptions` 里写明理由**（例如"网格化是本风格的语言"），**豁免必须写理由，不许静默跳过**。

### 6.2 鼓机美学

> 鼓机美学（标志例：Roland TR-808）**故意不给 hi-hat / snare 任何力度变化**——
> **冷、平，而且以此为荣。**

★ 这是一个**正当的风格选择**，不是偷懒。
但它和"忘了做力度"在规格上长得一样——**所以必须写进 exemptions 才区分得开。**

## 8. 实测：EDM 与别的风格

仓库实测语料 里 edm 10 首：

| 指标 | edm | pop | jazz |
|---|---|---|---|
| roster 规模（中位） | 32 | 36 | 22 |
| 段落数（中位） | 10 | 10 | 9 |
| 开场就在场的乐器比例 | 21% | 21% | 16% |
| 中途进场的乐器数 | 26 | 29 | 20 |
| **提前退场的乐器数** | **20** | 16 | 10 |

**读法**：EDM 的**退场比流行多**（20 vs 16）——与 §3.1"只剩鼓的段落"一致。
**但差距不如 R&B（28）大。**

⚠ **不要引用 BPM**：检测出 edm 中位 129、范围 68–152，
beat tracking 在电子音乐上有倍频误判（68 显然是 136 的一半）。
