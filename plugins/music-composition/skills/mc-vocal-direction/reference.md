## 0. 这些内容对用生成后端的人还有用吗

**一半有用，一半不用。**

| 内容 | 用生成后端时 |
|---|---|
| 话筒选型、摆位、近接效应 | **不用**——但 §1 的"配对逻辑"仍然是**挑 voice persona 的思路** |
| 监听（cue mix）的设计 | **不用** |
| 人声链参数（§3） | **参考**——用来判断生成人声缺了什么 |
| De-Esser 与齿音 | **有用**——生成人声的齿音问题很常见 |
| §4 录音标准 | **有用**——它定义了可交付人声的格式底线 |

> 保留完整内容的理由：本库的 L4 编译层支持 MIDI/DAW 后端，那条路要用真人录。
> 而且这些参数是**判断生成结果好坏的参照系**——
> 知道一条好人声是怎么做出来的，才知道模型输出缺什么。

## 1. 话筒选型

**摄影类比**：话筒 = 镜头；话放 + 声卡 = 机身；DAW = 胶片。
**同一支话筒经过不同话放，声音不同。**

| | 动圈（ダイナミック） | 电容（コンデンサー） |
|---|---|---|
| 特性 | 结实、便宜、不需供电 | 纤细易损、贵、需幻象电源 |
| 定位 | **现场演出标准** | **录音棚标准** |
| 声音 | — | "声音就是更好"——**连气息都能收到**，高低频响应均匀 |

**怎么选**：**让歌手实际唱、通过话筒听**。检查三点：
1. 声音的硬度/饱满度**适不适合这首歌**
2. 想要的**中频**有没有被收到
3. **歌手对着它唱舒不舒服**

**按编曲配对**：

| 编曲 | 话筒 |
|---|---|
| 柔和 | 柔声话筒 |
| 硬 | 硬质性格的话筒 |
| 摇滚冲击力 | **中低频有个性**的 |
| R&B 质感 | **闪亮（キラキラ）的高频** |

> 有录音师在场时，**用大白话说你的感觉就行**：
> "想更华丽一点"、"想要更亮的声音"、"想更有夏天的感觉"——怎么说都行。
> ★ 这条和 `SKILL.md` §2.2 是同一个道理，也同样适用于写提示词。

## 2. 摆位、距离、环境

| 项 | 要点 |
|---|---|
| **朝向** | 尽量正对话筒。**盯着歌词纸唱会录到"柔焦的声音"**——谱架和话筒的几何关系要提前规划 |
| **但别要求过头** | 要求太多会让歌手僵硬。**宁可让歌手动起来，录到有律动的人声**（跺脚的"咚"会被棚里地毯吸掉） |
| **近接效应** | 越靠近话筒**低频越被强调**——保持适中距离；要摇滚味时**故意贴着录**也是一个选项 |
| **高度关系** | 话筒在嘴正前方是基准；**嘴在话筒上方 → 收到更多低频；嘴在话筒下方（话筒从上俯角）→ 收到更多高频** |
| **迁就习惯** | 平时抱着吉他唱的、习惯坐着唱的，就按他的习惯布置 |

**特殊情况**：歌手因为监听太清楚而变神经质、唱不好时——
**故意降级话筒**，或**在 cue mix 里加大混响**。

### 2.1 监听（cue mix）

- 歌手自己的声音在耳机里多大**由歌手决定**，但太大会**难以把握音准**
- 节奏声部强会给人声律动，但会**盖住作为音高参照的声部**
- ★ **不建议在监听链里重压缩**：歌手听不到自己的动态，妨碍成长；
  "越唱越用力却没有任何触觉反馈"反而会唱出单薄的声音

## 3. 主唱人声链（目标：人声从伴奏里"走出来"）

**按顺序**：

| # | 处理 | 参数（实例） | 要点 |
|---|---|---|---|
| 1 | **压缩** | WAVES Renaissance Compressor，**Ratio ≈ 4:1（4.27:1），Attack 16 ms，Release 160 ms**（起音略慢） | **不要压死**——常规段落表头几乎不动，把阈值设在**副歌电平升高时压 3–4 dB**。目的是"稍微抹平人声的起伏" |
| 2 | **限制器** | WAVES L1 | 提整体响度。Maximizer 能**在保留演唱抑扬的同时提响度**（快被埋掉的部分会被抬起来） |
| 3 | **EQ** | WAVES Renaissance Equalizer | **高频提升**强调声音的 edge 成分；**低频 125 Hz 附近也提**（实例：151 Hz 峰，**+6.9 dB**）——这个频段"听起来不太像人声"，却能抬起人声**潜在的厚度与存在感**（接近欧美歌手质感的手法）。注意电平上升、小心削波 |
| 4 | **短延时** | AVID Mod Delay II，**走 send** | 产生类似合唱的宽度感。过量会"糊（にじみ感）"——**设在刚好听得见的临界点** |
| 5 | **混响** | AVID Reverb One | 最后**薄薄**加一层 |
| 6 | **最终平衡** | — | 人声处理完后若想让伴奏更突出，**把整条人声轻轻拉下来** |

### 3.1 R&B 的"贴在最前面"手法

**多段压缩**：WAVES C4（4 段，主要强调低频和高频）= **同时当 EQ 和压缩用**，
人声会"平贴在最前面"。

**代价**：**副歌之类的人声表情会被压平**——
在 R&B 以外的流行乐里，这有摧毁人声表情的风险。

**做这类处理时，用自动化微调音量，保住歌曲固有的抑扬。**

### 3.2 De-Esser

> De-Esser = **"专注于齿音频段的压缩器"**（实例：**FREQ 7.0 kHz / RANGE −5.0 dB**）。

**过头会产生含混的"大舌头"人声**——
这反过来证明了**辅音有多重要**（见 `SKILL.md` §2.3）。

> ★ 生成后端的人声齿音常常过重或过轻。这条给了判据：
> **能听出"大舌头"就是 De-Ess 过头了**，宁可留一点。

## 4. Treatment 的两个具体手法

### 4.1 消除喷麦（pop noise）——"瞬时 EQ"法

1. 找到喷麦点，**只循环播放那一小段**
2. 插入**陡峭的高通滤波器**，把截止频率**从低往高慢慢抬**，直到"噗"消失
   （实例：**300 Hz 附近，精确值 309.6 Hz**）
3. **只把那一段离线渲染导出**，**原位贴回原轨**，**两端做交叉淡化**接上

### 4.2 驯服失控的人声（电平大起大落）

- **压缩实例**：WAVES Renaissance Compressor，
  **Attack 24.9 ms / Release 16.6 ms / Ratio 4.72:1** + WAVES L1
- ★ **阈值是关键**：设在"骑着临界点"上——
  **太浅电平差缩不下来，太深演唱会变得不自然**
- 压缩还不够时：用**推子自动化**把小波形部分抬起来收尾
- > DAW 时代，**完全不用压缩、全靠自动化找平是完全可行的**——
  > 它甚至能画出压缩跟不上的复杂曲线，且毫无不自然。**推荐先用自动化找平。**

## 5. 和声与 double 的 EQ 实例

参数属于混音库，这里只留实例值供参照（型号定义见 `SKILL.md` §5）：

| 型 | EQ 思路 |
|---|---|
| **型 1**（全声上方和声） | **让和声从主唱的频段里逃开**：大幅削低频，**挖掉中频的"芯"**，必要时反而强调高频 |
| **型 3**（内敛下方和声） | 削低频。实例：**110 Hz low cut，123 Hz −10 dB，247 Hz −4.9 dB，621 Hz −4.2 dB**（整体中低频衰减） |
| **型 4**（合いの手） | **先动 EQ 改质感**（收音机音色也行）；整组共用空间效果，链：**EQ → 压缩 → 合唱 → 延迟** |
| 混响配合 | 型 1、型 2 用**高频丰富的混响/延迟**补辉煌感；型 3 **减直达声、增混响**降存在感 |
