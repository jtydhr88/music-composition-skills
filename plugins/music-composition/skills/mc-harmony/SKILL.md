# 和声：功能与色彩（Harmony）

**这个 skill 分两半，用的时候要分清你在哪一半：**

| 半 | 干什么 | 在 §几 |
|---|---|---|
| **功能** | 给旋律配上说得通的和弦 | §2–§5 |
| **色彩** | 把说得通的和弦变得好听 | §6–§7 |

★ **顺序不能反。** 先有功能骨架，再上色彩。
直接从色彩起手的结果是"每个和弦都很高级、连起来不知道在干嘛"。

## 1. 动笔前必填

| 必填 | 问法 |
|---|---|
| **① 调** | 大调还是小调、哪个调。**所有级数记号以它为准** |
| **② 和声节奏** | 一小节几个和弦？**★ 全曲一小节一个是最典型的套路** |
| **③ 这段要什么色彩** | 用 §6 的词回答，不是"好听一点" |
| **④ 哪里必须最稳、哪里必须最不稳** | 决定终止式放哪 |

## 2. 三功能

| 功能 | 性格 | 成员 |
|---|---|---|
| **T（Tonic）** | 稳定 | **I、VIm**（VIm 是 I 的"替身"） |
| **S（Subdominant）** | 轻度不稳，推向 D | **IIm、IV** |
| **D（Dominant）** | 不稳，想回 T | **V、VIIm(♭5)**（V 压倒性常见） |

**D 的不稳必须"解决"到 T，这个心理需求正是音乐前进动力的来源。**

★ **IIIm 被排除在这张表外**——它是变色龙，既能当 T 也能当 D，见 §6。

---

## 3. 三种终止式

| # | 型 | 感觉 | 例 |
|---|---|---|---|
| 1 | **T → D → T** | 像"起立、鞠躬、坐下"，简单有力 | C→G→C（I→V→I）、Am→G→C（VIm→V→I） |
| 2 | **T → S → D → T** | 张力逐步上升，一举解决到 T——**最令人满足** | C→F→G→C、Am→Dm→G→C |
| 3 | **T → S → T** | 不经过 D 就回 T；S→T 通常是 IV→I，即**阿门终止（变格终止）** | C→F→C |

**同功能连用**：同功能的和弦可以串起来。
例 C→Am→F→Dm→G→C（I→VIm→IV→IIm→V→I）——
I+VIm 串成 T，IV+IIm 串成 S，整体仍是 T→S→D→T。

---

### 3.1 ★ 终止式与情感：唯一一家管歌词的（Kachulis）

本库三家和声来源都不管歌词在说什么，这一层出自 Kachulis《The Songwriter's Workshop: Harmony》（p0163–0174）：

| 终止 | 情感 |
|---|---|
| 完全终止 V → I | 坚定 |
| 半终止（停在 V） | 不确定，制造紧张 |
| **虚伪终止** | 暧昧的惊喜，且三个落点各不同：**V → VImin 悲哀；V → IV 惊喜；V → VI 大三和弦 明朗欢快的惊喜**（p0169） |
| 变格终止 IV → I | 宗教感、精神性 |
| 混合终止（大调借小调 ♭VI – ♭VII – I） | 悲喜混合，摇滚布鲁斯尤其有效 |

各调式的完全终止长得不一样（p0163–0165）：大调 V–I；小调 ♭VII–Imin 或 V–Imin；布鲁斯 V7–IV7–I7；混合利底亚 ♭VII–I；★ **多利亚没有完全终止**。

### 3.2 家与离家：三种段落形状（p0176–0193）

| 段落 | 形状 |
|---|---|
| 主歌加副歌 | **家 – 离家 – 家** |
| 主歌 | **家 – 离家**，停在 V 推进副歌 |
| 桥段 | **离家 – 离家**，以非 I 起、结束在 V，张力最大 |

副歌两种造法：只用一个终止反复；或只在主题句上用终止，★ **主题句出现之前避免主和弦**（p0182–0187）。
段落衔接：主歌停 V，副歌起 I 是完全终止式衔接；副歌起 VImin 是虚伪终止式衔接，有意外感（p0191–0193）。

★ **段落对比的四条和声判据**（p0195）：每段起始和弦不同；每段至少一个新和弦；**只在副歌出现完全终止**；每段乐句长度不同。
写完对一遍这四条，四条都没做到的两段听起来会是同一段。

### 3.3 和弦色彩改词义：润色词语与润色乐句（Kachulis p0149–0160）

同一个音上的同一个词，配不同和弦，意思就变：**大三和弦充满希望、强力和弦有力自信、小三和弦悲伤内省、七和弦忧郁性感**（p0149–0150）。
本库以前没有"和弦 → 歌词意义"这条线。

**润色乐句的工序**（p0152–0160）：找出乐句里两三个重要音，**做一张多列的候选和弦表，每列对应一个小节**，然后组合着试；同一小节放两个和弦能造一点动力。
配套一个用途分组（p0082）：IImin–IIImin–IV–V、IV–V、IImin–V、VImin–V 这一组是"倾向 V"的进行，专门用来制造紧张、通往副歌。

## 4. 逐小节配和声的流程

1. **确认基本盘**：写出这个调的 I、IIm、IV、V、VIm 及其功能，再写出三种终止式
2. **逐小节列候选**：取这一小节的旋律音，找出**构成音包含它们**的自然音和弦
   - 旋律音正好等于某和弦的组成音 → 直接候选（如 A·F·C → F）
   - 多个和弦都包含 → 并列候选（如 B♭·D → B♭ 或 Gm，都是 S）
3. **用终止式裁决**：如果前三小节已经构成 T→S→D，第四小节就该回 T——挑 T 功能的候选
4. **结束规则**：全曲落在最稳定的 **I** 上最好
5. **T 既是终点也是起点**：在 T S D T S T D T 这样的功能链里，**一个 T 常常被前后两个终止式共用**

### 4.1 一个走完的例子（F 大调，3/4，8 小节）

候选表：F(I,T)、Gm(IIm,S)、B♭(IV,S)、C(V,D)、Dm(VIm,T)

| 小节 | 旋律音 | 候选 | 裁决 |
|---|---|---|---|
| 1 | A·F·C | F（构成音完全吻合） | F（T） |
| 2 | B♭·D | B♭ 或 Gm（都是 S） | 都行 |
| 3 | E·G·C | C | C（D） |
| 4 | A | F 或 Dm（都是 T） | 前三小节已 T→S→D，这里回 T |
| 5–8 | 同法 | B♭ → F → C → F | S→T→D→T，落在 I |

**结果**：F → B♭(或Gm) → C → F(或Dm) ／ B♭ → F → C → F

> **经验法则：先尽量往终止式框架里套，是进步的捷径。**
>
> ★ **失效条件**：真实歌曲里违反理论的例子比比皆是。
> 硬要"终止式必须绝对成立"，本身就会产出不自然的进行——**保持弹性，凡事有例外。**

### 4.2 两条初学者的代换规则（及它们的边界）

**IIm 与 IV 互换（S 功能组内）**——这条最稳。任达敏《流行与爵士和声学》把 ii、IV、vi 归进同一个下属功能组，"最常见的就是下属功能组和弦的相互替代"（p0134）：I-IV-V7-I 换成 I-ii7-V7-I 或 I-vi-V7-I，声部级进都更顺（p0135）。爵士乐里这条走得更远——IV 换成 ii7 之后，实践中 ii7 反而比原本的 IV 更常见（p0280）。

**I 用 IIIm 代换：两套判据不一样，别混用**

- 走"变色龙"这条路（见 §2、§6），IIIm 顶替 I 的时候色彩比 VIm 更暗，也更容易被听成朝 D 方向的过渡。
- 任达敏那套古典／爵士功能划分里，iii 反而归进**属**功能组，和 V、vii°7 同组（p0134）；他明说 iii 对 I 的解决力比 V 弱，"iii-I 的和声力度比较弱"，不建议让 iii 顶替终止式里的 I（p0135）。他给 I 在大调里更标准的代换对象其实是 VIm：因为 I 的和弦音大半被 VI 和弦包含，但这条**只在大调成立**，换用之后 I 后面的 V 通常也要跟着改写成 ii-V（p0279）。
- 连用副和弦本身有代价：一段旋律里正和弦几乎全被 iii、vi、ii 这类副和弦替换、又落在 VIm 上，听感会整个滑向关系小调，不再是原来的大调（p0118、p0120 例1-20）。

## 5. 小调（以和声小调为基础）

小调的功能表与三终止式同构，但 **V 要用大三/属七**（来自和声小调的升七级），
否则 D→T 的解决力消失。详细的自然/和声/旋律小调对照表见 [reference.md](reference.md)。

## 6. 色彩手法：症状 → 手法速查

| 想要 | 首选手法 |
|---|---|
| **更有推进力／更鲜明** | 副属和弦、二五 |
| **更爵士／更时髦** | 张力音、连锁二五、裏和弦 |
| **切なさ（怅惘）、一抹阴影** | **下属小调（S.M）**、IIIm7 |
| **半音下行的低音线** | 分数和弦、裏和弦、经过减和弦、クリシェ |
| **同一个和弦挂太久，想要内部运动** | **クリシェ**、sus4、保续音 |
| **避开平白属七的套路感** | 属小调、裏和弦、不解决的 V7sus4 |
| **忧郁／酷／即兴感** | 布鲁斯与蓝调音 |
| **整段气氛大换** | 转调引子（→ `mc-modulation`） |
| **整段重配** | §7 九步表 |

### 6.1 各手法一句话

| 手法 | 做什么 |
|---|---|
| **分数和弦** | 指定低音，做出平滑或半音的低音线 |
| **IIIm7** | ★ **变色龙**：既能当 T（I 的代理）又能当 D（V 的代理）。切换看上下文 |
| **副属和弦（Sec.D）** | 在任何"临时充当 T 的和弦"前面放它的 V7 |
| **二五（ii–V）** | 把一个属和弦拆成 IIm7→V7，推进力加倍 |
| **裏和弦（三全音代换）** | V7 → ♭II7。低音走半音，味道更冲。不合适时加 ♭5 |
| **下属小调（S.M）** | IV→IVm(6)，或用 ♭VI△7／♭VII7 代换。**怅惘感的主要来源** |
| **旋法味（多利亚 IV／属小调）** | 借调式色彩，避开功能和声的直白 |
| **sus4** | 延迟解决。**不解决的 V7sus4** 可以完全避开属七的套路 |
| **张力音（9/11/13）** | 加色不改功能 |
| **クリシェ（半音线）** | 和弦不动，内声部半音移动——治"和弦挂太久" |
| **经过减和弦** | 填进大二度的空隙 |
| **保续音（Pedal）** | 低音不动，上面换和弦 |
| **布鲁斯／蓝调音** | ♭3、♭5、♭7 的擦音 |

（每一条的完整用法、可用张力音表、禁用组合见 [reference.md](reference.md)。）

## 7. ★ 九步重配和声表

**给一个平淡的进行，按顺序试。每一步都以耳朵为最终裁判。**

| # | 做什么 |
|---|---|
| 1 | **七和弦化**（三和弦 → 七和弦）。**不要到处都加**，看整体平衡 |
| 2 | **代理替换**：I ⇄ IIIm7/VIm7，IV ⇄ IIm7，V7 ⇄ VIIm7(♭5)/IIIm7 |
| 3 | **插入副属**：每个"临时充当 T 的和弦"前面试着放它的 V7 |
| 4 | **属和弦二五化**：每个属七都检查能否拆成 IIm7→V7 |
| 5 | **属和弦裏代换**：要半音低音或更冲的味道时，V7 → ♭II7 |
| 6 | **借下属小调**：IV→IVm(6)，或 ♭VI△7／♭VII7，做怅惘 |
| 7 | **大二度空隙插 dim7**、**分数和弦做平滑低音**、**sus4 做延迟解决** |
| 8 | **撒张力音**：按 reference 的表配 9/11/13 |
| 9 | ★ **最后问自己：是不是做过头了？** |

### 7.1 ★ 第 9 步是这张表最重要的一步

> **"绝不要把和弦切得过碎。"**
> 直白的摇滚/流行尤其要提防啰嗦——**简单最好的情况同样多。**

**自检动作**：把升级后的版本和原版轮流放。
**如果说不出升级版好在哪里，就退回去。**
和声的复杂度不是分数，是**手段**。

### 7.2 逐步升级演示

同一个骨架 `C → Am → Dm → G`（I → VIm → IIm → V，循环进行）：

| 步骤 | 进行 | 用了第几步 |
|---|---|---|
| 原始 | `C → Am → Dm → G` | 自然音三和弦 |
| 七和弦化 | `C△7 → Am7 → Dm7 → G7` | 1 |
| 插副属 | `C E7 Am C7 F D7 G`（I III7 VIm I7 IV II7 V） | 3 |
| 二五化 | `C → Bm7(♭5) → E7 → Am → Em7(♭5) → A7 → Dm7 → G7` | 4 |
| 裏 + 张力 | `Em7 → E♭7 → Dm7 → D♭7 → C△7(9)`（半音下行低音收尾） | 5+8 |
| 加怅惘 | `C → Am → Fm6 → G7sus4 → G7` | 6+7 |

> ★ 注意这六行**不是越往下越好**。它们是六种不同的东西。
> 选哪一行由 §1 的必填③决定，不由"高级程度"决定。

## 8. 三个常用骨架（详表在 `mc-progressions`）

| 名 | 进行 | 功能 |
|---|---|---|
| **循环进行** | I → VIm → IIm → V | T→T→S→D。**可以无限重复**，骨架中的骨架 |
| **逆循环** | IIm → V → I → VIm | S→D→T→T。即从 S 段起头的循环进行；大调里比循环用得还多 |
| **卡农型** | I → V → VIm → IIIm → IV → I → IIm → V | ★ 它的魅力在于**从各和弦的构成音能抽出一条级进下行的旋律线，到最后一个和弦转而向上**——"一线希望忽然出现"的情绪效果 |

**逆循环最常见的发展**：重复两次、第二次落在 I；或重复时把末尾的 VIm 改成 **VI 大三**：
`Dm→G→Em→Am ／ Dm→G→C→A`

## 10. 写完后必过

- [ ] **先有功能骨架，再上色彩**，不是反过来
- [ ] 每一段的和声能说得出它的**功能链**（T S D T…）
- [ ] 全曲落在 **I** 上（要余韵才反着做，且写明理由）

- [ ] 跑完九步表后**问过"是不是过头了"**，且说得出升级版好在哪
- [ ] 级数与字母**双记**齐全
