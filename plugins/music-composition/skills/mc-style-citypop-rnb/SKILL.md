**这个风格的三根支柱：借来的爵士和声、抢拍的贝司、刻意的空。**

## 1. 动笔前必填

| 必填 | 问法 |
|---|---|
| **① city pop 还是 R&B** | ★ 两者的律动与人声完全不同（§7） |
| **② 年代感** | 70s–80s 原版？2010s 复兴版？还是当代 neo-soul？ |
| **③ 律动往前还是往后** | ★ city pop **往前赶**，neo-soul **往后坐**。这是两个方向 |
| **④ 谁负责"空"** | ★ 这个风格的性格来自留白，**留白要指定给谁** |

## 2. ★ 移植表

| 手法 | 可搬出去吗 | 说明 |
|---|---|---|
| **丸サ进行（IV–III7–VIm–I）** | ✅ **完全可搬** | 已在 `mc-progressions` §2.4。"几乎任何旋律放上去都显得时髦" |
| **F/G 型分数属代理** | ✅ 可搬 | ≈ G7sus4(9)，比 G7 含蓄精致 |
| **七和弦化 + 适度张力** | ✅ 可搬 | 但**密度要控**——满编张力会变爵士 |
| **贝司抢拍、鼓守网格** | ✅ ★ **可搬，而且是最值钱的一条** | 见 §4 |
| **Rhodes / 电钢的音区限制** | ✅ 可搬 | §5.2 |
| **16 分闷音刷弦** | ⚠️ 半搬 | 很强的风格标记，搬进别的风格会立刻被听成 city pop |
| **gated snare** | ⚠️ 半搬 | 强 80s 标记 |
| **萨克斯 solo** | ⚠️ 半搬 | 同上，且容易显得刻意怀旧 |
| **"留白即风格"** | ✅ ★ **可搬，该搬** | 见 §8 |

★ **判据**：
> **和声与律动可以自由借；音色（闷音刷弦、gated snare、sax）是标记，借了就会被认出来。**

## 3. 和声

### 3.1 它借的是爵士，但降了密度

| 来自爵士 | city pop 的用法 |
|---|---|
| 七和弦、九和弦 | ★ **默认就是七和弦**，不是"升级选项" |
| 张力音 9/11/13 | **用，但一次一两个**，不像爵士满编 |
| 二五、副属 | 大量使用 |
| **Sus / 分数属代理** | ★ **F/G 是心头好** |
| 变化属、减音阶 lick | ❌ **不用**——那会变成爵士 |

★ **这条差别是本 skill 的核心**：
**city pop 的和声是"爵士的词汇 + 流行的语法"。**
词汇借满，语法（功能进行、段落、副歌中心）仍然是流行的。

### 3.2 标志性进行

见 `mc-progressions`：
- **丸サ进行 4361**（`IV–III7–VIm–I`）—— city pop / neo-soul 的同义词
- **`IV△7–IIIm7–IIm7–I△7`** —— 流行/R&B 标准（"Lovin' You"）；
  ★ **循环回去前插一个 #IVm7(♭5) 非常时髦**
- **`C△7–D7–F–F/G`** —— 漂浮感，副属 II7 指向的 V7 始终不来

## 4. ★ 律动：抢拍贝司 + 守网格的鼓

**这是这个风格最可复制、也最常被做错的一条。**

**实测样本（example-01，112 BPM）**：

| 声部 | 偏移 | 作用 |
|---|---|---|
| **贝司** | **−12 ms（抢拍）** | ★ **这首歌"往前赶"的唯一来源** |
| 干净吉他 | **+8 ms（拖）** | 与贝司拉开，**产生宽度错觉** |
| **鼓** | **0** | ★ **守网格，做参照系** |

### 4.1 为什么必须有一件守网格

**"抢拍"是相对的。** 所有人一起抢只是速度快了一点，听不出往前赶。
**必须有一个不动的参照物，抢才成立。**

★ 这也是 `mc-rhythm-section` §2.0 那条"量化是逐乐器的决策"在具体风格上的落点。

### 4.2 贝司与底鼓的关系

city pop 通常用**交织式**（`mc-rhythm-section` §7.1）——
需要时重合加厚低频，不需要时拆开，**保住贝司自己的旋律线条**。
★ **这个风格的贝司是有旋律的**，不是只打节奏点。

### 4.3 feel

`straight16`（不是 swing）。16 分音符的密度来自**闷音刷弦**，不是来自摇摆——这两者听感相近，容易混着判断，选错会连累 §4 的抢拍判断（抢拍量的基准是"直"的网格，摇摆网格上"抢拍多少 ms"这个说法本身就不成立）。feel 怎么选的通用步骤（先风格后速度、backbeat 判据、in the crack 这类中间档怎么处理）见 `mc-rhythm-section` §1.1，这里不重复。

## 5. 编制

### 5.1 一份实测的 roster（example-01）

| 乐器 | 角色 | 频段 | 进 / 退 |
|---|---|---|---|
| **原声鼓 + gated snare**（70 年代收音） | 律动 | 60 Hz–12 kHz | A1 / end（**D 段整段静默**） |
| **Precision Bass**，指弹、短延音 | 低频 | 40–250 Hz | A1 / end |
| **Rhodes Mk I + 轻 chorus** | 和声铺底 | 200 Hz–2 kHz | I / end |
| **Strat 单线圈，16 分闷音刷弦** | 织体 | 1–3 kHz | A1 / **C2**（★ 之后不再出现，把空间让给萨克斯） |
| **Prophet 类锯齿单音，慢滑音** | **记忆点** | 1.5–4 kHz | I / end（★ **只弹 hook，不做垫底**） |
| **弦乐群，高把位长音** | 色彩 | 400 Hz–6 kHz | C1 / end（A2 退出一次，C2 再回来） |
| **次中音萨克斯** | 旋律 | 250 Hz–4 kHz | **D** / O（★ **全曲过半才进场，Outro 是它的**） |
| **女声**，气声偏多、不贴脸 | 旋律 | 200 Hz–8 kHz | A1 / **C3**（★ **Outro 无人声**） |

★ **三处设计都是本库强规则的体现**：
1. **萨克斯全曲过半才进场** —— 编制必须有中途进场（**59/59 强规则**）
2. **吉他 C2 退场、人声 C3 退场** —— 至少一件提前退场（**59/59 强规则**）
3. **合成器只弹 hook 不垫底** —— 非人声记忆点（lint #8）

### 5.2 ★ 音区纪律

**这个风格最容易糊的地方是 200–500 Hz，因为 Rhodes、弦乐、人声都在那儿。**

实测解法：
- **Rhodes 限制在 C3–C4**
- **弦乐只写 C4 以上**

★ **这是"错开音区"的教科书用法**（`mc-texture-layering` §4.2 解法②）。
**不是靠 EQ 切，是靠写的时候就不写进去。**

## 6. 一份实测的频谱预算

| 频段 | 归谁 | 争抢者 | 解法 |
|---|---|---|---|
| **40–120 Hz** | 贝司 | 鼓 | Kick 侧链 Bass，30 ms 释放；Bass 在 Kick 击点让出 3 dB（**让频**） |
| **200–500 Hz** | Rhodes | 弦乐、人声 | ★ **错开音区**：ep 限 C3–C4，strings 只写 C4 以上 |
| **1–3 kHz** | 闷音吉他 | 合成主音 | ★ **交替出现**：吉他只在 A/B 段，合成主音只在 I/C/O 段的句尾空档 |
| **6–12 kHz** | 鼓 | 弦乐 | 弦乐高频滚降 8 kHz，把空气感留给 hihat |

★ **四条冲突，三种解法都用上了**（让频 / 错开音区 / 交替出现）——
这正是 `mc-texture-layering` §4.2 要求的"三选一并写明"。

## 7. city pop 与 R&B 的分野

| | **city pop** | **R&B / neo-soul** |
|---|---|---|
| **律动方向** | ★ **往前赶**（贝司抢拍） | ★ **往后坐**（laid back） |
| **人声** | 相对直白，混得靠后 | **大量装饰、转音、ad-lib** |
| **和声** | 爵士词汇 + 流行语法 | 更接近爵士，**张力更满** |
| **编制** | 乐队编制（鼓贝吉键 + 弦 + 管） | 更依赖**采样与编程** |
| **人声叠加** | 副歌加和声 | ★ **和声堆叠是主要手段**（`mc-vocal-direction` §5 四型全用） |

★ **两者共享和声语汇，但律动方向相反。**
**把 city pop 的抢拍贝司放进 neo-soul 会直接毁掉那个风格。**

### 7.1 ★ 一条实测：R&B 是最"减法"的风格

仓库实测语料 里 hiphop-rnb 10 首：

| 指标 | hiphop-rnb | pop | jazz |
|---|---|---|---|
| **提前退场的乐器数（中位）** | ★ **28** | 16 | 10 |
| 开场就在场的乐器比例 | **24%** | 21% | 16% |

**读法**：R&B/嘻哈**开场铺得最满，但撤得也最多**——
它的结构感来自**不断撤掉东西**，不是不断加东西。

★ **可直接搬**：写 R&B 时，`subtraction_events` 要写得比别的风格多。

> 语料这 10 首是 hiphop-rnb 混装。**hip-hop 一侧**（第三种时间感、808 分工、采样织体）在 `mc-style-hiphop`；本节只说 R&B 半边。

---

### 7.2 ★ 西洋 R&B 与日本 R&B 是两个东西（藤谷）

| | 西洋 R&B | 日本 R&B |
|---|---|---|
| 音符 | **少** | **多** |
| 气质 | 阴暗、冷酷 | 闪烁、明亮 |
| 和声 | 受爵士影响，常用很复杂的和弦 | |

（p0154）。写之前先说清要哪一个，"R&B"这三个字母不够用。原则：**音符少的时候，每一个音都要好听，否则编曲不成立**；
拍子是 R&B 的命脉，大鼓小鼓的音色要讲究（p0154）。

### 7.3 西洋向 R&B 的编程定式（藤谷 p0157–0162）

- **鼓全用合成音色，按 hip hop 手法设拍**；三件音色都要"像黑胶采样出来的"，厚实粗糙，采样特性是大鼓小鼓响时 hi-hat 也同时共鸣，那就是 groove（p0157）
- **两层大鼓**：主大鼓，加一个"噗"一声的超低音大鼓，**只出现在小节开头**（p0157）
- **hi-hat 打八分音符，完全不调力度**，淡淡地逐格输入（p0160）；过门放在偶数小节结尾，用刮唱片音效（p0160）
- **贝斯只弹根音**，只落在第一拍与第三拍后半的八分音符弱拍上；音符尽量延长但不盖过第二拍第四拍的开头，太长就拖泥带水（p0161）
- **电钢琴只用二分音符或全音符**，颤音与音色够好就舒服；别的类型要厚实辽阔感时也用它（p0162）

这与 §4 的 city pop 律动正相反：那边贝司抢拍、鼓守网格；这边贝斯只有两个落点、hi-hat 无力度。同一个"R&B"标签下是两套编制纪律。

## 8. ★ "留白即风格"

这个风格的性格**有一半来自不弹什么**。

实测样本里的三个减法事件：

| 位置 | 做什么 | 为什么 |
|---|---|---|
| **C2 之前** | **最后半拍全体静止（含鼓）** | ★ **第二段副歌不能靠更响赢第一段，靠前面那个洞** |
| **D 段** | 鼓与贝斯**整段撤出**，只剩电钢 + 人声 + 萨克斯 | ★ **全曲能量最低点必须在 C3 之前，否则 C3 不成立** |
| **A2** | 弦乐与半数吉他退出 | ★ **第二段主歌要比第一段更空，而不是更满** |

★★ **这三条理由都值得单独记住**，它们是通用的编曲智慧，不只属于这个风格
（→ `mc-arrangement-arch` §3）。
