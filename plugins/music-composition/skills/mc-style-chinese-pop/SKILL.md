## 2. ★ 移植表

**华语流行在编曲层面大量借用 J-POP 与欧美，这本身不是问题——问题是借错了地方。**

| 手法 | 可搬进华语吗 | 说明 |
|---|---|---|
| **J-POP 的和声语汇**（王道进行、小室、卡农） | ✅ **完全可搬**，且已经是主流 | 见 `mc-progressions` |
| **J-POP 的 A–B–サビ 三段构成** | ✅ 可搬，已是主流 | `mc-form` §2.2 |
| **J-POP 的 B メロ（预副歌）** | ✅ 可搬 | 它在华语里就是"预副歌" |
| **欧美的 Verse–Chorus 二段** | ✅ 可搬 | 更早的华语流行多是这个 |
| **city pop 的编制与音色** | ✅ 可搬 | 见 `mc-style-citypop-rnb` |
| **J-POP 的旋律密度** | ⚠️ **半搬** | ★ **日语一个音节一个音，中文一个字一个音但字更"重"**——照搬日式密度会让中文咬不清 |
| **英语流行的连音/弱读处理** | ❌ **不可搬** | 中文没有弱读音节，硬搬会变成含混 |
| **说唱的英语 flow** | ⚠️ 半搬 | 中文说唱的重音规律不同。★ rap + 中国风的混合分工见 `mc-style-hiphop` §8.1 与 `mc-workflow` §2.4 |
| **旋律的大跳位置** | ⚠️ ★ **受倒字约束**（§3） | 这是华语最硬的一条本地约束 |

★ **一条判据**：
> **和声、编制、结构可以自由借；旋律的音高走向不行——它被声调锁住。**

## 3. ★ 倒字：华语最硬的本地约束

### 3.1 是什么

普通话有四个声调，**每个字自带一条音高走向**。
如果旋律进入这个字的音程方向与字的调型冲突，听众就会听成**另一个字**——这叫**倒字**。

**作词库 `lw-tone-check` 的判定模型**（仓库内部有同模型的检测器脚本，不随包发布）：

```python
contour  = TONE_PITCH[t][1] - TONE_PITCH[t][0]   # 本字的调型
incoming = notes[i] - notes[i - 1]               # 进入本字的音程
if   contour > 0 and incoming < 0: 风险          # 阳平该升却下行
elif contour < 0 and incoming > 0: 风险          # 去声该降却上行
elif contour == 0 and abs(incoming) >= 3: 风险   # 平调被大跳带出走向
```

★ **注意这个模型的关键**：比较的是**进入本字的旋律音程**与**本字自己的调型**，
**不是**"前一个字的尾音 vs 后一个字的头音"。
（后者是第一版的写法，它测不出教科书里的标准案例。）

### 3.2 对编曲的三条后果

**判定与修正归作词库，但它会反过来约束编曲：**

1. ★ **旋律的大跳位置不自由** —— 大跳落在哪个字上，那个字就有倒字风险。
   → 这限制了 `mc-melody` §3 的跳进安排
2. ★ **"曲先"在华语里代价更高** —— 先写好旋律再填词，
   填词人要同时满足意思、韵、和不倒字。**词先或边写边改更常见**
3. **同一条旋律换词就要重查** —— 第二段主歌的词不同，倒字风险点也不同。
   → `form[].note` 里要标"此段旋律与 A1 相同但词不同，需复查"

### 3.3 自检动作

> **把每段的旋律和词一起念一遍。念出来像别的字，就是倒字。**
> 系统一点的判法用作词库 `lw-tone-check` §2.3：只查每段最高音、每句首字、大跳落点三类位置。

## 4. 语料现状：能查到什么

### 4.1 反向 ARR-SPEC（3 条）

仓库实测语料 里 `style_layer: mc-style-chinese-pop` 的有 **3 条**：

| 指标 | 值 |
|---|---|
| BPM 中位 | 137（范围 131–141） |
| 段落数中位 | 10 |
| 时长中位 | 217 秒 |

⚠ **3 条不足以支撑任何风格论断。** 列在这里只是说明"能查到什么"。
★ 上面那个 137 只是三条的中位，**不要当作华语流行的 BPM**。谱面能查到的 BPM 见 §4.3。

### 4.2 歌本语料

| 书 | 页 | 性质 |
|---|---|---|
| 《同一首歌·20 世纪中国流行歌曲精品》 | 569 | 20 世纪曲集，做四对齐表的选曲池 |
| 《2012 流行歌曲精选》 | 140 | 做和声/曲式统计 |
| 《我的流行吉他》1 / 2 / 4 | 100/111/107 | ★ **带和弦标记与逐段和声分析**，适合做进行统计 |

### 4.3 歌本实测（五本歌本 931 条，只存谱面参数）

华语四本（《同一首歌》二十世纪作品 379 首、《2012 流行歌曲精选》102 首、《我的流行吉他》三册 83 首，合计 n=564）：

| 指标 | 值 |
|---|---|
| 调号（首调主音，转调取起始调） | F 15%、C 13%、G 13%、D 10%、♭B 10%、E 9%、A 9%、♭E 8%（n=550） |
| 拍号 | 4/4 69%、2/4 25%、3/4 4%、6/8 2%（n=546） |
| BPM，只计谱面标了数字的 | P10 58 / 中位 **84** / P90 120（n=78，**几乎全来自《同一首歌》的二十世纪作品**） |
| 速度与表情术语 | 中速 58、稍慢 28、稍快 24、渐慢 18、深情地 12、热情 9、自由地 8 |
| 谱面标注的体裁 | 影片插曲、影片主题歌、新疆民歌、陕西民歌、歌剧选曲 |

**读法**：
- 华语歌本的调号分布很平，F、C、G、D、♭B 五个调占六成，没有一个调过两成；当代作品（2012 精选与吉他谱）以 C、G、D 和 ♭E 为主，吉他谱大量用变调夹回到 C／G 指型。
- ★ **当代华语流行的 BPM 本库仍无实测**：78 首有数字的几乎都是二十世纪的民族与影视歌曲，中位 84 不能外推到今天的流行曲；2012 精选与吉他谱只给速度术语（中速、稍慢）不给数字。要 BPM 得等音频语料。
- 2/4 拍占四分之一，是二十世纪歌本的特征，当代华语流行几乎全是 4/4。

英文 Fake Book（1955–1986 Billboard 前二十，n=367）的调号、和弦循环与骨架在 `mc-case-studies` reference §1.2，作欧美参照。

### 4.3 ⚠ 一次统计尝试及其结果（诚实记录）

**做过的事**：从《我的流行吉他》系列的笔记里提取"1=X"调号与逐段和声进行，
转成级数，统计四和弦窗口。

**结果**：只解析出 **10 首**，最常见的窗口是
`I V I V`（3 次）、`V I IV V`（3 次）、`I IV IV I`（2 次）……

**结论**：★ **样本太小，且结果是通用进行，不构成华语特征。**
**没有把它写成"华语流行的特征进行"** —— 那会是对数据的误用。

## 5. 粤语：声明为后加层

**用户的原话**：
> **"粤语韩语不应该成为 block 我们的进度，我们架构层面本来就是分层＋组合，本来就可以后期加的。"**

**所以粤语在这里是一个声明的接口，不是一个空洞：**

| 项 | 说明 |
|---|---|
| **协音** | 粤语九声，约束比普通话四声**严得多**。判定归**作词库** |
| **本 skill 能说的** | 只有"它存在且更严"，不给具体规则 |

★ **不要在底本读完之前编造粤语规则。** 粤语协音是有精确体系的，猜出来的一定是错的。

---

### 5.1 分期对编曲的含义（黄志华《粤语流行曲四十年》）

| 期 | 底子 | 编曲上意味着什么 |
|---|---|---|
| 1949–1959 | 两个来源：上海传下来的**国语时代曲**，与黄金时代的**粤剧粤曲**（p0047） | 粤语歌一开始就有两种底子，一个是时代曲的舞厅乐队，一个是粤曲小调的锣鼓与梆黄。写"老派粤语味"先选底子 |
| 1960 年代 | 受粤语电影操纵，风格要么**过于粤曲化**，要么**"画虎不成反类犬"的西化**（p0048）；多为旧曲新词，如粤剧小曲填词（p0048） | ★ 书里点名的两种失败正是今天做"复古粤语"最容易掉进的坑：锣鼓一响就成了粤曲，西化一过就四不像 |
| 1980–1982 | 台湾校园民歌吹袭，鼓励青年自己写作（p0051）；市场淡风，唱片公司起用新歌手与新填词人（p0051–0052） | 民歌吉他编制进入粤语歌：木吉他为主、编制轻、词重于曲 |
