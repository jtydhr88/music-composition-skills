## 1. 王道 J-POP 类（明亮、抓耳、大调循环）

| 级数 | Key=C | 情绪／场景 | 备注 |
|---|---|---|---|
| I–IV–V–I | C–F–G–C | 直白、简单、好填词 | **王中王**。竹内まりや「元気を出して」、湘南乃風「純恋歌」 |
| IV–V–I–VIm | F–G–C–Am | 副歌开场王牌、壮大 | 从 IV 起头容易形成强烈的归主流向；舞曲里也通用 |
| IV–V–VIm–I | F–G–Am–C | 明亮中带一缕切なさ | 横扫 90 年代日本流行；**和上一条搭配使用可微调切なさ的量** |
| I–VIm–IV–V | C–Am–F–G | 可爱、跳脱 | 循环性强、指法好按 |
| I–IV–VIm–V | C–F–Am–G | 换场重音 | C–F 之后出现 Am 的意外感；**在抒情曲桥段末尾只用一次最有效** |
| I–IIIm–IIm–V | C–Em–Dm–G | 酸甜（明亮却怅惘） | 简单的摇滚感，适合前奏 |
| I–IIm–IIIm–IV | C–Dm–Em–F | 温暖、上行的期待 | 根音级进上行；**循环接缝好处理**——前奏/间奏/solo 轮着用 |
| IIIm–IV–V–VIm | Em–F–G–Am | 期待感堆积、很酷 | 低音级进上行；变体 4563、6345（"放大期待"型）；首和弦换成 C/E 会更轻 |
| VIm–V–IV–I | Am–G–F–C | 抒情、流畅下行 | 级进下行、旋律性低音；近年流行常见，收得平静而美 |
| I–IIm7–IV–V7 | C–Dm7–F–G7 | 情绪必然上升 | 根音 1→2→4→5 上行；从主歌进副歌到抒情、快歌都极广泛 |

## 9. 五条实务经验（三本底本的共识）

1. **代理和弦互换**：同功能可互换（T: C/Em/Am；SD: F/Dm；D: G/Bm(♭5)）。
   G→Bm(♭5) 增加凄楚，Em→G 增加循环性，C→Am 让结尾变暗，C→Em 增加复杂度——
   **只换一个和弦就能改变故事的颜色**；旋律可能打架，**最终由耳朵裁决**。
2. **循环 vs 解决**：要循环就把 **D 功能放在进行末尾**，好流回开头的主；要解决就落在 T。
   功能流动 = 稳定（T）⇄ 不稳定（SD/D）的**起承转合**。
3. **副属是自然引入调外音的第一件武器**：A7→Dm、B7→Em、C7→F、D7→G（重属）、E7→Am——通常用七和弦形。
4. ★ **低音决定和弦功能**：上方和弦相同，换一个低音就改变整个进行
   （上方 C 三和弦 + 低音 A = Am7）。**从低音线反推和弦也是有效的作曲方法。**
5. ★ **顶音就是旋律**：耳朵把最高音当旋律。同一进行通过**排列（转位）重新设计顶音线**——
   **"改变排列本身就是作曲"。**
