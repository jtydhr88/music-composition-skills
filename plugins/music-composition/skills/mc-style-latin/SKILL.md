# 拉丁风格层（Latin）

**这个风格层的三根支柱：先选对家族、让 clave 当语法、把网格交给铃件而不是鼓。**

★ **"拉丁"不是一个风格，是三个互不通婚的家族。**
《The Drummer's Bible》在巴西一章开头就把话说死了：**不要把巴西与 Afro-Cuban 混为一谈，
两者各有各的特征与具体节奏，一首歌被标成 "Latin" 时，先得知道该打哪一类节奏型**（p0059）。
本 skill 做的就是这个分家的决定，具体鼓型不在这里。

## 1. 动笔前必填

| 必填 | 问法 |
|---|---|
| **① 哪一个家族** | ★ Afro-Cuban／巴西／加勒比／拉丁摇滚。**四选一，选完才有下一问**（§8） |
| **② 家族内的哪一支** | Afro-Cuban 还要再分 son-salsa／mambo／cha cha／songo／mozambique／guaguanco／6-8 bembe；巴西再分 samba／batucada／bossa／baião；加勒比再分 calypso／soca／ska／reggae |
| **③ clave 是哪一条、从哪一侧起** | ★ son 还是 rumba，2-3 还是 3-2。**这一条定了，所有两小节图形的方向就定了**（§3） |
| **④ 有没有真的打击乐手** | ★ 决定分工。没有时鼓这一件要一人顶掉 conguero、timbalero、bongo bell 三个人的活（p0029）；有多位时反过来，人人主动减量（p0099、p0103、p0109） |
| **⑤ 真本还是移植** | 做正宗的那一支，还是拿它的表层做流行编曲的色彩。★ 决定 §2 移植表怎么用 |

## 2. ★ 移植表

| 手法 | 可搬出去吗 | 说明 |
|---|---|---|
| **baião 的附点八分＋十六分底鼓** | ✅ **完全可搬，而且早就搬走了** | 它同时是 Charleston 的底子，也是大量 hip-hop groove 的底子（Groove Essentials p0095）。搬走后没人会听成巴西 |
| **巴西式的"第 4 拍后半先现"** | ✅ 可搬 | 第 4 拍的"+"上先现是巴西音乐的常见特征（Jazz Guitar Groove p0037），本质是先现，通用层已有（`mc-rhythm-groove` §3） |
| **bossa 的换和弦时点** | ✅ ★ **可搬，而且最值钱** | 奇数小节拍首换、偶数小节提前半拍换（藤谷 p0104）。这几乎是一条即插即用的改编开关，任何曲子照它改就带 bossa 味 |
| **"每小节最后一个十六分干净收住"** | ✅ 可搬 | songo 的标志（Groove Essentials p0104），书里直接说这是十六分音符类音乐的重要特征，不限于拉丁 |
| **conga／tumbao 的两小节循环** | ⚠️ 半搬 | 作为打击乐铺底可搬；一旦配上 clave 与 bell，整段就被听成 Afro-Cuban |
| **cascara／palito 图形** | ⚠️ 半搬 | 它是"补 clave 另一侧"的东西（p0034、p0048），脱离 clave 只剩一条切分十六分线 |
| **Cha Cha bell 的持续四分** | ❌ **基本不可搬** | 极强的风格标记，一响就是 cha cha（p0038） |
| **Mambo bell / Mozambique bell** | ❌ 不可搬 | bell 型本身就是这两支的身份证（p0037、p0108） |
| **clave 本身** | ❌ ★ **不可搬** | 它不是一个节奏点缀，是一套支配全体声部方向的语法（§3）。把 clave 贴进一首非拉丁的歌，只会得到一条拧着的两小节循环 |
| **one drop（第 3 拍鼓边与底鼓同击）** | ❌ 不可搬 | 一响就是 reggae（p0074） |
| **"与打击乐手同台就减量"的纪律** | ✅ ★ **可搬，该搬** | 见 §4.3。这是拉丁能给一般编曲的最有价值的一条 |

★ **一条判据**：
> **能不能搬，看它依不依赖 clave。**
> 依赖 clave 的（bell 型、cascara、tumbao 的方向感）搬出去就废；
> 不依赖 clave 的（底鼓附点型、先现的时点、减量的纪律）随便搬。

## 3. ★ clave：这一层的语法

### 3.1 它是什么

Clave 在西班牙语里是"key"，指钢琴的键那个 key，与开锁的 llave 不同（p0030）。
定义上它是**两小节的节奏型**，分成有三个音的"3"侧与有两个音的"2"侧，
**从哪一侧起都可以**，所以有 3-2 与 2-3 两种排法；它是大多数 Afro-Cuban 节奏的地基（p0012）。

★ **写进编曲里的意义**：clave 不是一个可选的打击乐轨，
**它是决定其他所有两小节图形朝哪个方向排的语法。**

### 3.2 son 还是 rumba

| | son clave | rumba clave |
|---|---|---|
| **"3"侧最后一音落在** | ★ **第 4 拍上** | ★ **第 4 拍的"+"上** |
| **唯一的区别** | 就是上面这一行（p0030） | |
| **多出现在** | 较传统的支系：Mambo、Cha Cha（p0013） | 较现代的支系：Songo、Mozambique（p0013） |

**判据**：先定支系，clave 的种类跟着定，不用另外拍脑袋。
Guaguanco 是 3-2 rumba（p0036）；Mambo 是 2-3 son（p0037）；
Mozambique 与 Songo 都是 2-3 rumba（p0039、p0040）；Pilon 基于 2-3 son（p0049）。

### 3.3 2-3 还是 3-2

**判据**：看合奏的乐句从哪一侧开始。
Mambo 从"2"侧或"3"侧起都行（p0037），Guaguanco 通常从"3"侧起（p0036）。
所以这不是一个音乐学问题，是一个**乐句起点的记谱问题**：
先写出旋律与合奏型，再决定把 clave 的哪一侧对上第一小节。

★ **一旦定了，所有两小节的图形要一起翻。**
cascara 与 palito 的音相对 clave 的位置是固定的，
**无论 3-2 还是 2-3，它与 clave 的对位关系都不变**（p0034、p0048）。
翻 clave 时不能只翻 clave 那一轨，整组两小节图形一起翻。

### 3.4 什么叫跟着 clave 走

三个可查的落点，写的时候拿它们当校验点：

| 名字 | 位置 | 用处 |
|---|---|---|
| **bombo** | ★ clave"3"侧**第 2 拍的"+"** | 底鼓最正宗的落点。要更古巴，就把底鼓收到只剩它（p0035）；Guaguanco 强调的也是它（p0036） |
| **ponche** | 4/4 小节**第 4 拍**上的重音 | 过渡用的图形（p0013） |
| **每小节最后一个十六分** | 干净收住 | songo 的签名，也是十六分类音乐的通则（Groove Essentials p0104） |

**判据（跟着走）**：每一条两小节的固定图形，它的重音要落在与 clave 同一侧。
**判据（打架）**：图形的重音落到了相反的那一侧。
典型症状是 **bombo 那个"+"落进了只有两个音的那一小节**，
于是低频的重心与 clave 的三音侧背向而行，整段听起来拧。
> ⚠ 拉丁圈把这种拧法叫 cruzado，**这个词底本未覆盖**，上面这条判据是从
> "palito／cascara 与 clave 的对位关系恒定"（p0034、p0048）这一条反推出来的。

### 3.5 什么时候不要写 clave

- **songo 的脚踩 rumba clave**：groove 本身没立稳之前加它，会打断整体的感觉（p0040）。
  ★ 可以推广：**clave 是加在稳定之上的，不是用来建立稳定的**。
- **本来就没有 clave 的支系**：Bomba（p0042）、Cumbia（p0047）、Plena（p0050）通常不打 clave，别硬贴。
- **Pilon**：有 clave 作为底子，但通常不由鼓手打出来（p0049）。

### 3.6 6/8 那一支

Afro-Cuban 6/8 基于三拍子感，源自尼日利亚约鲁巴人，在古巴常叫 Bembe 或 Abakwa（p0013、p0031）。
**它有自己的 clave 与自己的 bell 型**（p0012）；bell 型与 6/8 clave 完全相同，
只多加两个音，那两个音要打得比别的轻（p0032）。

★ **写谱决策**：要与全曲的 4/4 段落互相换算，就记成 4/4 的三连音分组，
**书里说这么记的目的正是建立它与 4/4 古巴 clave 的关系**（p0031）；
要让演奏者按三拍子分句，就记 6/8。
数拍是这一支的主要难点，Groove Essentials 把 Nañigo 直接叫作"六对四的数拍问题"（p0106）。

## 4. ★ 律动分工：谁守什么

### 4.1 四个角色

| 角色 | 守什么 | 依据 |
|---|---|---|
| **conga tumbao** | 标准的、重复的 conga 图形，主要落在高音鼓 quinto 上 | p0013 |
| **bass tumbao** | ★ **贝司在 Afro-Cuban 里的主图形**；有鼓组时**底鼓通常用重音加倍或加强它** | p0013 |
| **piano montuno** | 重复的、切分的钢琴图形 | p0013 |
| **timbale cascara** | 两小节的壳上图形，**补 clave 的另一侧**；源自 palito，原打在挖空的竹子 gua gua 上 | p0012、p0048 |
| **铃件（bell）** | ★ **持续脉冲，守网格的就是它** | §4.2 |

### 4.2 ★ 谁守网格

**拉丁里守网格的不是鼓，是铃件与脚。**

- Cha Cha 的签名就是 cha bell 上**持续不断的四分音符**，hi-hat 常去加倍它（p0038）
- 6/8 的 hi-hat 脚**每个正拍踩一下**（p0033）
- Merengue、Soca、Ska 用 four on the floor 的底鼓当脉冲（p0042、p0072、p0073）
- Plena 的强特征就是**简单的四分底鼓**（p0050）

★ **为什么这条重要**：clave 是两小节的、切分的、不落在网格上的。
**如果没有一件在正拍上持续发声，clave 就没有参照物，听起来只是一串错拍。**
这与 `mc-style-citypop-rnb` §4.1 那条"必须有一件守网格，抢才成立"是同一个道理的两个落点。

### 4.3 与打击乐手的减量纪律

书里反复说同一件事，值得当规则记：

| 情形 | 做法 | 依据 |
|---|---|---|
| 没有打击乐手 | 鼓这一件要一人顶掉 conguero、timbalero、bongo bell 三个角色，对独立性要求极高 | p0029 |
| 有一位打击乐手 | 选音更少的变体（Cha Cha、Mambo、Merengue 都给了"与 conga 手合作用这个"的简化版） | p0038、p0043、p0100 |
| 有多位打击乐手 | ★ **主动减量避让**。Merengue 那条最直白：温和地减少自己的贡献，别踩别人的声部 | p0099、p0109 |
| 搞不清复杂的交互 | **只打那条 bell 型**。Mozambique 的重点本来就是 bell，tom 交互乱了先放掉 | p0108 |

★ **这四条可以整段搬到任何编曲里**：**编制越密，每个人写得越少。**

### 4.4 抢拍这件事，底本是怎么说的

- **巴西那支有明确的先现**：第 4 拍的"+"上先现是巴西音乐的常见特征（Jazz Guitar Groove p0037）。
- **bossa 里抢拍的是和声件，不是贝司**：吉他与电钢在偶数小节提前半拍换和弦，
  **贝斯一律在拍子开头换**（藤谷 p0104）。
- **Afro-Cuban 里底鼓与贝司是同一条线的两个面**：底鼓支撑贝司的 tumbao，**有时齐奏，有时拆分**（p0037）；
  Cumbia 的底鼓重复型通常直接匹配贝司手（p0047）；Samba 的脚在模仿 surdo 的同时配合贝司手（p0059）。

> ⚠ **"salsa 的贝司一律抢拍到前一个和弦上"这个说法，底本未覆盖。**
> 能支持的就是上面三条。写 `groove.push_pull` 时按这三条填，不要填查不到出处的毫秒值。

★ **可直接用的一条**：`arrangement.bass_kick_relation` 在 Afro-Cuban 里**默认是绑定式**
（底鼓用重音加倍贝司的 tumbao，p0013），与 city pop 的交织式正相反。

## 5. 巴西那支

### 5.1 surdo 是底层逻辑

鼓组上巴西那支的脚部（主要是底鼓）**在模仿 surdo 这面大鼓**，同时配合贝司手（p0059）。
Batucada 更进一步，**ride 手直接到落地 tom 上复制 surdo 的声音**，含制音击（p0061、Groove Essentials p0097）。

★ **编曲上的读法**：**巴西那支的低频不是"底鼓声部"，是一面被拆到鼓组上的大鼓。**
所以写巴西的低频时先问"这一下是 surdo 的哪一击"，再问它落在第几拍。

### 5.2 partido alto

Partido Alto 既是巴西最流行的 samba 支系之一，也是一条在 samba 与 bossa 里都用的节奏型；
传统上打在 agogo、cuica、pandeiro、tamborim 上，到了鼓组通常落在军鼓（p0013）。
Samba 的手部围绕它（p0059），Batucada 的军鼓打的是它（p0061），Bossa 的鼓边击变体之一也是它（p0064）。

★ **判据**：**同一条 partido alto 在三支里换了乐器与力度，风格就换了。**
图形本身不是风格标记，**承载它的那件乐器与力度才是**。

### 5.3 bossa 的"轻"从哪来

三个可查的来源，三个都要做到才成立：

| 来源 | 具体 | 依据 |
|---|---|---|
| **鼓的音色与奏法** | ★ **鼓组音色节制**，避开华丽的摇滚鼓组；**封闭式鼓边敲击是主流奏法**，所以要挑鼓边音好听的鼓 | 藤谷 p0105 |
| **触键与留白** | ★ **轻触，留空**；double-time 的暗示要极敏感地用 | Groove Essentials p0091 |
| **换和弦的时点** | 奇数小节拍首换、偶数小节提前半拍换，吉他与电钢照此，**贝斯一律拍首** | 藤谷 p0104 |

**并排的两说**：《The Drummer's Bible》说 bossa 的**底鼓与 samba 完全相同**，
差别在于速度更慢、更放松，以及和声借自美国爵士（p0063、p0064）；
藤谷则把重点放在编制与换和弦时点上（p0102–0108）。
★ 两说不冲突，合起来就是：**bossa ≈ samba 的骨架 ＋ 爵士的和声 ＋ 一整套减量的执行。**

### 5.4 samba 为什么不落定

Samba 的 feel 是**直中带极轻微的摇，从不落定在某一个地方**，乐队要"松而不糊"，
这两者有巨大区别；各件音量相等，hi-hat 去模仿 pandeiro（Groove Essentials p0092）。
快 samba 的底鼓要轻、向前流动，别踩在别的乐器上（p0094）。

**并排的两说**：Jazz Guitar Groove 说 **samba 与 bossa 的八分音符更接近平直**（p0040），
Groove Essentials 说它是直与微摇之间的液态（p0092）。
★ 写 `groove.feel` 时：**填 `straight16`，另在 `quantize_policy` 里写明"接近直，允许极小的不落定"**，
不要用 swing 比例去表达它。

### 5.5 baião

主要打击乐器是 zabumba 这面大底鼓，以切分节奏在两侧演奏（p0062）。
主节奏与巴西 clave 的第一小节相同，速度更接近 samba 而不接近 bossa（p0062）。
底鼓是经典的**附点八分接十六分**（Groove Essentials p0095）。
它不是 bossa 与 samba 的融合，但两者的节奏元素它都有（p0062）。

★ **这条附点型是本 skill 里最可搬的东西**（§2）：它同时是 Charleston 与许多 hip-hop groove 的底子（p0095）。

## 6. 编制与音区纪律

### 6.1 bossa 的编制是有必需件的

| 件 | 必需程度 | 说明 |
|---|---|---|
| **古典吉他（尼龙弦）** | ★ **必需** | 藤谷说 bossa 的主要演奏乐器绝对是它；**只要有吉他和歌唱就能表演 bossa**（p0104、p0107）。高音三根弦是尼龙，甜美柔和的音色从这里来（p0107） |
| 原声鼓组 | 标准编制 | 音色节制，鼓边音要好（p0105） |
| **原音贝斯** | 要真 bossa 就用它 | 想带一点流行感，电贝斯也行（p0106）。★ **这是一个明说的档位选择** |
| 钢琴或电钢 | 标准编制 | 电钢多指 Fender Rhodes 系；颤音、合唱、相位常用（p0107） |
| 打击件 | 常加 | 沙铃、三角铁、tamborim（六吋单面框鼓）、pandeiro（十吋鈴鼓）（p0108） |

示范曲的速度是 BPM 120（p0108）。

### 6.2 Afro-Cuban 那边的编制

- **打击乐三人组是默认**：conguero、timbalero、bongo bell 手（p0029）
- **Mambo 的历史配方**：美国 swing 的乐器编制、即兴与和声配置 ＋ 古巴 son 的节奏（p0036）。
  ★ 所以 mambo 段落配铜管是有来历的

各支系的传统件清单（Danzon 的关响弦、Plena、Merengue、Calypso 等）见 [reference.md](reference.md) §4。

### 6.3 一份 roster 建议

★ **以下频段位置是按乐器性质排的相对关系，本库未实测，没有实测的频率数值可引。**

| 件 | 角色 | 频段位置（相对） | 进／退的建议 |
|---|---|---|---|
| **surdo / zabumba / bombo** | 低频脉冲 | 最低 | 巴西与 baião 全程；它一走，那一支的身份就没了 |
| **原音贝斯** | 低频旋律 | 低 | 全程 |
| **conga（tumbao）** | 中低的手鼓循环 | 中低 | 可整段撤出做减法 |
| **timbale／tom 的 cascara 与 timbale 旋律** | 中频切分线 | 中 | ★ **与 bell 二选一更清楚**（§6.4） |
| **cowbell / agogo / cha bell** | ★ **守网格的持续脉冲** | 中高 | 要做段落对比就整段拿掉它 |
| **clave / rim click / palito / 木鱼** | 语法的可听化 | ★ **中高木质点，全曲最挤的一格** | §6.4 |
| **shaker / cabasa / güiro / 三角铁 / pandeiro** | 高频连续感 | 高 | 与 hi-hat 抢同一格 |
| **尼龙弦吉他（bossa）** | 和声 ＋ 律动 | 中 | ★ bossa 的必需件，不能中途撤掉 |
| **钢琴／电钢（montuno）** | 和声的切分循环 | 中 | montuno 段是最自然的进场点（§7.1） |

### 6.4 ★ 音区纪律：拉丁最容易糊的是中高频的木质点

**clave、rim click、palito、木鱼、cascara 打在鼓壳上的声音，全部挤在同一个中高频的窄点上。**
这是这一层最不一样的拥堵位置：别的风格挤的是中低频那一格（→ `mc-texture-layering`），这里挤的是一个**打击的瞬态点**。

三个现成解法，都是少写，不是后期修：

1. **减件**：有多位打击乐手时每人都主动减量（p0099、p0103、p0109）
2. **只留主干**：交互搞不清就只打 bell 型（p0108）
3. **换表面**：cascara 可打在闭合 hi-hat、落地 tom 的壳或框、cowbell、ride bell 之间挑一个（p0034），
   ★ **挑的时候就是在挑频段**

★ 这三条落在通用层就是 `mc-texture-layering` §4.2 的"错开音区／让频／交替出现"三选一，
**拉丁这一层几乎总是选"减件"。**

## 7. 和声

**通用的和声一律不在这里**：七和弦、张力音、二五、副属、分数和弦的体系去 `mc-harmony`，
bossa 借来的那套爵士和声本体去 `mc-style-jazz` §3。
这一节只写这三家特有的两条。

### 7.1 montuno：它同时是一条图形和一个段落

| 含义 | 说明 |
|---|---|
| **① 一条图形** | 通常由钢琴演奏的**重复、切分**的音型（p0013） |
| **② 一个段落** | ★ **Afro-Cuban 编曲里支持即兴的那一段**（p0013） |

**历史的旁证**：真正的 Danzon 有固定编排（paseo、长笛主题、前奏重复、小提琴段）；
son 进来之后多出第四部分，原称 "Nuevo Ritmo"，后来就叫 Mambo，**即兴是从这里引入的**（p0048）。

★ **两条可以直接用的编曲判据**：
1. **montuno 段是曲式上的即兴出口。** 要给 solo 留位置，就把它放在 montuno 段，
   不要在主题段里挖洞（曲式通论见 `mc-form`）。
2. **montuno 的和声必须是短循环。** 一条重复的切分钢琴音型只有在和声也重复时才成立；
   段落的推进由密度与进场撤场提供，不由和弦提供。

> ⚠ **具体是哪几个和弦在循环，底本未覆盖。** 底本给的是图形的性质与段落的功能，没有给 salsa 的和弦级数。
> 要写具体循环，去 `mc-progressions` 取，并在 `form[].harmony` 里写清级数。

### 7.2 bossa 的和声

藤谷那一支的说法（p0103–0104）：

- 与爵士一样，**大量使用四和音、引伸音和弦、分数和弦**（p0103）
- ★ **旋律与和弦根音之间距离往往非常远，独特的飘浮感从这里来**（p0103）
- 开头的 **C△7(9)** 是 bossa 极常用的和弦：旋律停在五度是普遍情况，加上 M7 与 9 就比普通的 C 时髦（p0103）
- 想在某一小节做变化，把 C 换成 **C/E**（三音当低音）就有飘浮感（p0104）
- 结尾的 **D♭△7(9) → C△7(9)**：旋律停在最安定的 Do，上方和弦却让这个 Do 变成 M7，
  再半音下行接回主和弦收住（p0104）

《The Drummer's Bible》那一支（p0063）：bossa 的作曲者多来自中上层阶级，
**借用美国爵士的旋律性与和弦结构，但保留 samba 的鼓节奏**，速度更慢更放松。
两本都说和声来自爵士。
> ⚠ **"bossa 比爵士降了和声密度"这个说法，底本未覆盖。**
> 底本能支持的是"更慢、更放松"（p0063）与"四和音、引伸音、分数和弦照用"（p0103）。
> 要降密度，那是编曲决定，写进 `form[].harmony` 的注里，别当成风格定义。

### 7.3 换和弦时点是和声的一部分

★ bossa 那条**奇数小节拍首换、偶数小节提前半拍换、贝斯一律拍首**（藤谷 p0104）
在本库的体例里横跨两层：它既是和声节奏，也是律动。
写的时候两处都要落到：`form[].harmony` 写和弦，`groove` 那一侧写"和声件提前半拍、贝司不提前"。

## 8. ★ 三家（加一支）的分野

| | **Afro-Cuban** | **巴西** | **加勒比** | **拉丁摇滚** |
|---|---|---|---|---|
| **代表支系** | son-salsa、mambo、cha cha、songo、mozambique、guaguanco、6-8 bembe | samba、batucada、bossa、baião | calypso、soca、ska、reggae | 上面三家的节奏塞进摇滚曲式 |
| **有没有 clave** | ★ **有，而且是语法**（son／rumba × 2-3／3-2） | 有"巴西 clave"这个说法，用在 bossa 与 baião（p0064、p0062） | ★ **基本不用 clave** | 看借的是哪一支 |
| **低频的角色** | 底鼓加倍贝司的 tumbao（p0013、p0037） | ★ **底鼓在模仿 surdo**（p0059） | four on the floor（soca、ska）或第 3 拍的 one drop（reggae） | 简化过的标准摇滚底鼓（p0131） |
| **守网格的** | 铃件的持续脉冲 | 手上的连续十六分（模仿 pandeiro，p0092） | 底鼓 | 标准摇滚的 backbeat |
| **feel** | 直 | ★ **直与微摇之间，不落定**（p0092） | ska 直、reggae 在夹缝里（p0073、p0074） | 直 |
| **典型速度** | 中到极快，见 reference | 快，samba 起于 ♩=170（p0059） | 中速偏慢到中速 | ♩=110–120，到 double-time 的 200–232（p0131） |

★ **不能混的理由书里明写**（p0059）。混的后果是两套两小节语法互相拧，
低频重心与铃件的脉冲对不上，听起来既不古巴也不巴西。

### 8.1 加勒比内部的两组区别

| 一组 | 区别在哪 | 依据 |
|---|---|---|
| **Ska vs Reggae** | 两者都在第 3 拍打鼓边击；★ **Ska 是直拍 ＋ four on the floor，这就是区别** | p0073 |
| **Reggae 的 one drop** | 第 3 拍的鼓边击与底鼓**同时作为一个音**击出，名字从这里来 | p0074 |
| **Calypso vs Soca** | Calypso 底鼓更切分、没有持续的军鼓型，groove 不如 Soca 明显；Soca 更快、four on the floor 更重 ＋ 突出的切分军鼓 | p0071、p0072 |
| **Ska 的吉他** | ★ **强烈均匀地强调所有反拍**，标志性声音的主要来源，吉他手叫它"反向伴奏" | p0073 |

★ **Calypso 有一条执行细节值得单独记**：**响弦必须关掉，用掌击军鼓做出交叉棒的声音，
否则听起来像行进乐队，不像加勒比节奏组**（Groove Essentials p0089）。

### 8.2 拉丁摇滚是一个明确的"降真实度"档位

- 定义：把 Afro-Cuban 与巴西的节奏融进摇滚曲式，常同时用上这三家的打击件（p0131）
- ★ 它使用的鼓组型**比正宗的那两章更不真实、往往更简化**（p0131），这是书里的定位，不含贬义。
  简化是为了避免与其他打击乐手重复；单独演奏时可以再扩回去，接近更真实的声音（p0131）
- 速度：从标准摇滚的 ♩=110–120，到 double-time 的 Afro-Cuban／巴西感的 ♩=200–232（p0131）
- 现成的配方：标准摇滚 ＋ cha cha（p0131）、baião ＋ 摇滚感（p0132）、mambo 但底鼓改成强调两小节的第 1 拍（p0133）

★ **给流行编曲的读法**：**想要"拉丁味"而不想承担正宗的分工，拉丁摇滚这一支就是给你的合法档位。**
选它，并在 `meta` 里写明选的是它，比写一个含糊的 "latin" 诚实得多。

## 10. 写完后必过

- [ ] 说清了是**哪一个家族的哪一支**，没有出现笼统的 "latin"
- [ ] ★ **没有把巴西与 Afro-Cuban 的图形混在同一段里**（p0059）
- [ ] clave 定了种类与起侧，**理由是支系，不是随手**
- [ ] ★ 所有两小节的固定图形**朝同一侧**，bombo 落在"3"侧第 2 拍的"+"上（§3.4）
- [ ] 本来无 clave 的支系（bomba、cumbia、plena）**没有被硬贴一条 clave**
- [ ] ★ **有一件在正拍上持续发声**当网格（铃件或 four on the floor），clave 有参照物
- [ ] 打击件的数量与分工匹配（有几个人就减到几个人的量，§4.3）
- [ ] 中高频的木质点**只留了该留的那几件**，解法写明是减件／只留主干／换表面
- [ ] bossa：尼龙弦吉他在场，鼓用鼓边击，**和声件提前半拍换而贝司拍首**
- [ ] samba：低频写的是 surdo 的击
- [ ] montuno 段的和声是**短循环**，且它承担即兴或密度推进
- [ ] ★ 往别的风格搬时查过 §2：**没有把依赖 clave 的东西搬走**
- [ ] 要的只是"拉丁味"时，明确选了拉丁摇滚这个档位并写进 `meta`（§8.2）
